## 1. 项目目标与范围

项目名称为“基于中控架构的智能安全 v1.0”中的部分功能开发。目标是在起重机现有摄像头和中控硬件上实现五项视觉安全检测功能，并使三一具备后续维护、参数调整和模型迭代能力。功能由外包合作开发，原文要求交付数据、完整工程源码、配置、训练工程与量化脚本、可运行安装包、测试及运维资料；模型文件的单独移交范围待确认。

| 编号 | 本项目范围内的功能 | 通俗含义 |
| --- | --- | --- |
| F-01 | 载荷附近人员检测 | 监测吊钩地面投影周围危险区域的人员。 |
| F-02 | 载荷下方人员检测 | 监测吊载下方及相关遮挡区域的人员。 |
| F-03 | 大臂下方人员检测 | 监测大臂轴线下方扇形区域的人员。 |
| F-04 | 高度限位开关安装状态识别 | 判断限位开关重锤及钢丝绳是否正确安装。 |
| F-05 | 卷扬冰雪检测 | 判断主、副卷扬卷筒上的冰雪覆盖是否超限。 |

**系统边界：**本系统是安全感知与告警辅助系统，输出检测结果、目标位置、置信度、告警事件和日志；不直接控制起重机底层动作。最终控制执行策略由三一主控系统决定。（原文 §1.4）

## 4. 使用场景和术语

| 术语 | 本文含义 |
| --- | --- |
| 作业状态 | 起重机发生回转、变幅、起落钩或伸缩臂等动作。 |
| 静止状态 | 未发生上述作业动作；前三项人员检测仍需返回结果，但原文规定不报警。 |
| 吊钩投影 | 吊钩在地面的投影点，用作 F-01、F-02 区域中心。投影计算方法待设计。 |

| 告警与提示 | “告警”表示触发安全预警；原文另写静止时“提示”但不报警，提示形式待确认。 |

## 6. 核心功能深度分析

本章的 F-01～F-05 是**需求功能单元**。每项先列可追溯的原文条目，再指出输入、状态、输出和验证中需要落地的接口或证据；它们不是当前源码中的模块名称。

### 6.1 F-01 载荷附近人员检测

| ID | 需求 | 原文依据 |
| --- | --- | --- |
| F01-01 | 功能开启后持续监测以吊钩地面投影为中心、半径 **10 米**范围内的人员。 | §3.1.1～3.1.2 |
| F01-02 | 作业状态下，在范围内连续 **3 帧**检出人员时报警。 | §3.1.2 |
| F01-03 | 静止状态下，在范围内连续 3 帧检出人员时返回结果并记录日志，不报警；“提示”的展示方式待确认。 | §3.1.1～3.1.2 |
| F01-04 | 未输入回转、变幅、起落钩和伸缩臂工况数据时，在检测范围内检出人员应**立即报警**。 | §3.1.2 |
| F01-05 | 应识别全身、半身、穿戴安全帽或反光衣、局部遮挡及多人场景的人员，并过滤设备、物料和阴影等干扰。 | §3.1.3 |
| F01-06 | 应输出人员相对吊钩投影中心的距离与顺时针夹角。 | §3.1.4 |

**模块视角：**

- 输入：人员画面、吊钩地面投影所需信息和作业工况；输出人员检测、相对距离/角度及告警或记录状态（F01-01～04、F01-06）。
- 状态：作业连续 3 帧报警、静止记录不报警、缺工况立即报警是三个不同分支。
- 验证：原文第 8.1 节只按 5 米检测区布点，不能直接证明 6～10 米符合性；投影、标定、时延起止点和统计方法需确定（Q-01、Q-03、Q-04）。

### 6.4 F-04 高度限位开关安装状态识别

| ID | 需求 | 原文依据 |
| --- | --- | --- |
| F04-01 | 在备车阶段通过臂头摄像头识别三种状态：重锤未安装、重锤已装但起升钢丝绳未穿过中心孔、正确安装。 | §3.4.1、§3.4.3 |
| F04-02 | 上车上电、功能开启并处于准备状态，且大臂为基本臂长、根部角度 **≥5°**时开启检测；另一段写“超过 5°”，5°边界待确认。 | §3.4.2、§3.4.4 |
| F04-03 | 累积检测帧数 **≥10**、中途静止 **≥15 秒**或根部角度 **＞75°**时结束检测并返回结果。 | §3.4.2 |
| F04-04 | 结果不是“正确安装”时，输出具体异常状态并报警。 | §3.4.4 |
| F04-05 | 详细章节要求准确率 ≥92%、召回率 ≥92%、结果响应 ≤15 秒、帧率 ≥1；第 6.1 节另写精确率 ≥92%。 | §3.4.4、§6.1 |

**模块视角：**

- 输入与启动：臂头画面结合基本臂长、准备状态和根部角度决定是否启动（F04-01～02）。
- 状态与输出：累积检测 ≥10 帧、静止 ≥15 秒或角度 ＞75°时结束；输出三种安装状态，异常报警（F04-03～04）。
- 验证：恰好 5°是否启动、结束条件同时发生时如何取值、总体 ≥5 fps 与专项 ≥1 fps 如何适用，原文未定；原文第 8.4 节的三状态测试不能独立证明完整状态机（Q-06）。

### 6.5 F-05 卷扬冰雪检测

| ID | 需求 | 原文依据 |
| --- | --- | --- |
| F05-01 | 通过卷扬摄像头监测主、副卷扬卷筒表面冰雪，计算覆盖面积占比，并区分冰雪与结构纹理、漆面色差；功能描述还提到钢丝绳积雪。 | §3.5.1、§3.5.3 |

**模块视角：**

- 输入与输出：主、副卷扬画面用于识别卷筒冰雪并计算覆盖比例；钢丝绳积雪的具体判定尚未定义（F05-01）。
