# 双轴评审清单

## 规格符合度

- [ ] 默认值是 `startup`，而不是空字符串或随机旧值。
- [ ] 每个已声明的场景映射到规格中的稳定原因标识。
- [ ] 不相关的状态转移没有被伪装成已覆盖。
- [ ] 新键仅为兼容性扩展，未改动现有键的含义。
- [ ] 不改变 `network_select`、失败计数、超时、RBMaster 或 AT 指令行为。

## 代码质量与运行安全

- [ ] 原因来自受控常量/枚举，不含 AT 应答、文件内容或未限制字符串。
- [ ] 所有固定长度字符串都保证 NUL 结尾。
- [ ] 继续使用现有状态文件的 mutex 与临时文件 `rename()` 原子写入。
- [ ] 不在状态写出热路径新增昂贵扫描、阻塞 I/O 或不必要日志。
- [ ] 未把不可运行的交叉编译或设备验证描述为“已通过”。
