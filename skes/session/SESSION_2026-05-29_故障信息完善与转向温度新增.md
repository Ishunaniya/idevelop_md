## 二、新增实现：BMS故障 CAN 解析

### 2.1 BMS故障帧协议（0x0CFF8003）

表格定义：CAN0 `0x0CFF8003`（29位扩展帧），byte0~byte6 共 43 个独立故障位（BMSERR1~43），每个 2bit 或 1bit 表示一种子故障，byte3 bit0~1 为"总故障状态"（0正常/1预警/2一级/3二级）。

| 字节 | 故障编号 | 内容 |
|------|---------|------|
| byte0 | BMSERR1~4 | 单体/总压过高过低 |
| byte1 | BMSERR5~8 | 温度/压差类 |
| byte2 | BMSERR9~12 | SOC/绝缘/功率类 |
| byte3 | BMSERR13~19 | **总故障状态**（bit0~1）+ 低压供电/SOC跳变等 |
| byte4 | BMSERR20~27 | 通信/检测类 |
| byte5 | BMSERR28~35 | 继电器粘连/失效类 |
| byte6 | BMSERR36~43 | 传感器/充电/预充类 |

### 2.2 聚合设计

`bmsErr` 是单个 int，需要将 43 个 bit 映射为统一值：

- 检测：byte0~byte6 按位 OR，非零即有故障
- 取值：byte3 bit0~1（总故障状态）作为严重等级（0~3）
- 兜底：总故障状态=0 但其他字节非零时（理论异常场景），bmsErr 置 1
- 恢复：全字节清零 → bmsErr=0 → `updateFaultEntry` 自动将 type=6 条目从 faultList 移除

```cpp
// RealtimeStatusManager.cpp — 插入位置：0x0CFF7F03 之后，0x18FE7C03 之前
if (can_channel == 0 && can_id == 0x0CFF8003 && data_length >= 7)
{
    uint8_t any = b0 | b1 | b2 | b3 | b4 | b5 | b6;
    int severity = b3 & 0x03;  // 总故障状态
    int bmsErr = (any != 0) ? (severity != 0 ? severity : 1) : 0;

    realtime_status["chache"]["faultInfo"]["bmsErr"] = bmsErr;
    updateFaultEntry(realtime_status, 6, bmsErr);
}
```

## 三、新增实现：转向电机温度 / IGBT 温度

### 3.1 来源与协议

用户需求：
- 转向电机温度：CAN0 `0x0CFF030A` BYTE5，分辨率1，偏移-40，单位℃
- 转向IGBT温度：CAN0 `0x0CFF030A` BYTE6，分辨率1，偏移-40，单位℃

注：`0x0CFF030A` 原已用于 BYTE2（转向MCU软件版本），本次在同一帧内扩展解析 BYTE5/BYTE6。

### 3.2 实现要点

- 外层条件保持 `data_length >= 3`（保证软件版本解析不受影响）
- 内层追加 `if (data_length >= 7)` 单独守护温度解析，帧不足 7 字节时静默跳过
- `(int)can_data[5] - 40` 与现有 `driveMotorTemp`、`pumpMotorTemp` 写法完全一致

```cpp
if (data_length >= 7) {
    int strMotorTemp = (int)can_data[5] - 40;
    int strIGBTTemp  = (int)can_data[6] - 40;
    realtime_status["chache"]["runStatus"]["strMotorTemp"] = strMotorTemp;
    realtime_status["chache"]["runStatus"]["strIGBTTemp"]  = strIGBTTemp;
}
```
