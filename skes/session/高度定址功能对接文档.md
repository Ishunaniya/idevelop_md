# 高度定址功能 — Qt 对接文档

> 对接对象：Qt UI（skes-main_fork-lift）
> VEH 侧实现：skes-dataengine / SkesQtBridge
> 通信通道：skes-relay，Topic = `/skes/filter`
> 协议：SKES v0.8
> 对应需求图：`20260603-203933.png`（一键起升定址功能）

---

## ★ 0. 需求原文（重点）

下表为「一键起升定址功能」界面的原始需求，**这是本功能的对接基准**：

| 序号 | 界面按钮 | 高度值 | property_name | CAN 帧·字节·位 | 方向 |
|------|---------|-------|---------------|----------------|------|
| 1 | 启动1 | **3 m**  | `heightPreset1`     | 0x31D · BYTE1 · **Bit0** | 发送 |
| 2 | 启动2 | **6 m**  | `heightPreset2`     | 0x31D · BYTE1 · **Bit1** | 发送 |
| 3 | 启动3 | **8 m**  | `heightPreset3`     | 0x31D · BYTE1 · **Bit2** | 发送 |
| 4 | 启动4 | **10 m** | `heightPreset4`     | 0x31D · BYTE1 · **Bit3** | 发送 |
| 5 | 启动5 | **13 m** | `heightPreset5`     | 0x31D · BYTE1 · **Bit4** | 发送 |
| 6 | 停止   | —       | `heightPositioning` | 0x31D · BYTE1 · **Bit6** | 发送 |

### 每个按钮的行为要求（需求图逐条，重点）

每个「启动N」和「停止」按钮的动作完全一致，需满足：

1. **仪表令报文下发至 VCU** —— 按钮触发后，仪表（VEH）将命令写入 0x31D 对应 bit，随帧发送给 VCU。
2. **按下后显示置位**（实心/点亮）—— 触发瞬间该位置 1，界面图标点亮。
3. **不带记忆** —— 该位不持久化，掉电/重启后恢复 0。
4. **1 秒后自动置零位** —— 置 1 后保持 1000ms，到时自动归零，界面图标熄灭。

> ⚠️ 即「**脉冲信号**」：按一下 → 置 1 → 1 秒后自动归零。Qt **只在按下时下发一次**，不要发松开/结束命令。

### CAN 通道说明（重点）

> 需求图中标注的 **CAN1**，对应 **源码 / 实际硬件的 CAN0**（channel 0）。
> 0x31D 帧实际参数：**CAN0、扩展帧（ID | 0x80000000）、500ms 周期发送、脉冲位 1000ms 自复位**。
> 高度值（3/6/8/10/13 m）**不在本帧内**，存于 VCU，通过 PDO 参数读写（见第 4 节）。

## 1. 完整字段映射（0x31D BYTE1）

| Bit | property_name | 类型 | 记忆 | 说明 |
|-----|---------------|------|------|------|
| Bit0 | `heightPreset1` | 脉冲 1s | 否 | 高度1(3m) 定址启动 |
| Bit1 | `heightPreset2` | 脉冲 1s | 否 | 高度2(6m) 定址启动 |
| Bit2 | `heightPreset3` | 脉冲 1s | 否 | 高度3(8m) 定址启动 |
| Bit3 | `heightPreset4` | 脉冲 1s | 否 | 高度4(10m) 定址启动 |
| Bit4 | `heightPreset5` | 脉冲 1s | 否 | 高度5(13m) 定址启动 |
| Bit5 | `oneTouchLeveling` | 开关 0/1 | 否 | 一键水平（持续保持，无自复位） |
| Bit6 | `heightPositioning` | 脉冲 1s | 否 | **停止** 定址 |
| Bit7 | `horizontalStopSetting` | 开关 0/1 | **是** | 一键水平停止设置（VEH 持久化） |

## 2. 下发控制命令（QT → VEH）

### 2.1 通用格式

```json
{
  "version": "1.0",
  "id": "",
  "ts": 1717405200000,
  "msg_id": "<UUID>",
  "action": "request",
  "type": "properties",
  "data": {
    "type": "cmd_control",
    "data": [
      { "property_name": "heightPreset1", "data_type": "int", "data": 1 }
    ]
  }
}
```

- `msg_id`：**必填**，UUID，VEH 原样回显在 response 中。
- `data.data`：数组，可一次下发多个 property（PDO 参数除外，见 4.3）。

### 2.2 各操作下发说明

| property_name | data 取值 | 说明 |
|---------------|----------|------|
| `heightPreset1`~`heightPreset5` | 任意（建议 1） | 触发对应高度定址脉冲。**当前 VEH 不读取 data 值，收到即触发**。按下时发一次即可。 |
| `heightPositioning`（停止） | 任意（建议 1） | 触发停止脉冲。同上。 |
| `oneTouchLeveling` | `0` / `1` | 1=启动一键水平，0=停止。持续保持，无自复位。 |
| `horizontalStopSetting` | `0` / `1` | 一键水平停止设置开关，**VEH 持久化**，重启恢复上次值。 |

> ⚠️ 重点：`heightPreset*`、`heightPositioning` 是脉冲，**只在按钮按下时下发一次**。VEH 自动维护 1 秒置位与归零，Qt 无需发结束命令、无需自己计时。

## 3. 响应与状态推送（VEH → QT）

### 3.1 命令响应（response）

每条 `cmd_control` 都会收到一条 response：

```json
{
  "version": "1.0", "id": "", "ts": 1717405200005,
  "msg_id": "<回显请求的 UUID>",
  "action": "response", "type": "properties",
  "data": {
    "type": "cmd_control",
    "result": 0,
    "message": "OK",
    "data": [
      { "property_name": "heightPreset1", "result": 0, "data_type": "int", "data": 1 }
    ]
  }
}
```

| result | 含义 |
|--------|------|
| 0  | 成功 |
| -1 | 缺少 data |
| -2 | 未知 property_name |
| -3 | 参数非法（越界） |

### 3.2 图标状态即时推送（post）★重点

脉冲位（`heightPreset1~5`、`heightPositioning`）有独立的**即时状态推送**，让 Qt 图标精确同步亮灭，**不依赖 500ms 周期推送**——这正是满足需求「按下显示置位 / 1 秒后置零」的关键：

```
按下按钮
  └─ VEH 立即 POST  heightPresetN = 1   →  Qt 点亮图标
  （CAN 该位保持 1 秒）
1 秒后脉冲自动归零
  └─ VEH 立即 POST  heightPresetN = 0   →  Qt 熄灭图标
```

推送报文（`action=post`，无 msg_id）：

```json
{
  "version": "1.0", "id": "", "ts": 1717405201000,
  "action": "post", "type": "properties",
  "data": {
    "type": "filter_table",
    "data": [
      { "index": -1, "property_name": "heightPreset1", "data_type": "int", "data": 0 }
    ]
  }
}
```

> **Qt 实现要点**：图标亮灭直接监听这两条 post（值 1 → 亮，值 0 → 灭），**不要自己用定时器去猜 1 秒**，VEH 已保证两端都推送。

### 3.3 周期全量推送（500ms）

VEH 每 500ms 推一次全量状态（`data.type=filter_table`），开关类字段在这里取稳定值：

| property_name | 说明 |
|---------------|------|
| `oneTouchLeveling` | 当前一键水平开关状态 |
| `horizontalStopSetting` | 一键水平停止设置开关 |

> `heightPreset1~5`、`heightPositioning` 为脉冲，走 3.2 即时通道，不在 500ms 推送中作为稳定状态。

## 4. 高度目标值（PDO 参数）

需求图中的 3m / 6m / 8m / 10m / 13m 等高度目标值**存在 VCU 内**，不随 0x31D 下发，通过 PDO 参数读写。

### 4.1 参数清单（pumpSettings 分区）

| property_name | PDO addr | 含义 |
|---------------|---------|------|
| `pumpSettings.liftMaxHeight`  | 19 | 最大起升高度 |
| `pumpSettings.forkLevelAngle` | 20 | 货叉水平角度 |
| `pumpSettings.heightAddr1`    | 21 | **高度1 定址值（对应 3m）** |
| `pumpSettings.heightAddr2`    | 22 | **高度2 定址值（对应 6m）** |
| `pumpSettings.heightAddr3`    | 23 | **高度3 定址值（对应 8m）** |
| `pumpSettings.heightAddr4`    | 24 | **高度4 定址值（对应 10m）** |
| `pumpSettings.heightAddr5`    | 25 | **高度5 定址值（对应 13m）** |
| `pumpSettings.liftBufHeight`  | 29 | 起升缓冲高度 |
| `pumpSettings.dropBufHeight`  | 30 | 下降缓冲高度 |

> 注：3m/6m/… 是界面示例值；实际定址高度由 `heightAddr1~5` 的 PDO 值决定，可在参数页配置。单位/分辨率请与 VCU 协议核对。

### 4.2 读取（query）

```json
{
  "action": "request", "type": "properties", "msg_id": "<UUID>",
  "data": {
    "type": "query",
    "data": [
      { "index": -1, "property_name": "pumpSettings.heightAddr1", "data_type": "int" }
    ]
  }
}
```

响应：

```json
{
  "action": "response", "type": "properties", "msg_id": "<回显>",
  "data": {
    "type": "query",
    "data": [
      { "ts": 1717405200000, "index": -1,
        "property_name": "pumpSettings.heightAddr1",
        "data_type": "int", "value": 3000, "result": 0 }
    ]
  }
}
```

> 进入参数页下发 query 后，VEH 在后台异步向 VCU 批量读取 pumpSettings（addr 15~30），最新值写入缓存。VCU 离线时返回缓存旧值（日志打印 `bg read skip ... VCU offline`）。

### 4.3 写入（cmd_control，单参数异步）★重点

⚠️ **PDO 写入每次只能下发一个参数**，Qt 端需单独发一次 cmd_control：

```json
{
  "action": "request", "type": "properties", "msg_id": "<UUID>",
  "data": {
    "type": "cmd_control",
    "data": [
      { "property_name": "pumpSettings.heightAddr1", "data_type": "int", "data": 3000 }
    ]
  }
}
```

PDO 写入是**异步**的（VEH 写 VCU → 等回显），response 在写完成后才返回：

- 成功：`result=0`，`data[].data` = VCU 实际回读值。
- 失败/超时：`result=-6`，`data[].data` = 旧值；VEH 另发一条 `data.type=param_rollback` 的 post 推旧值，Qt 据此回滚 UI。

| result | 含义 |
|--------|------|
| 0  | 写入并回显成功 |
| -5 | PDO 参数名未知 |
| -6 | VCU 写入失败/超时 |

## 5. 时序图小结

### 高度定址（脉冲，满足需求「置位→1s归零」）
```
Qt 按下「启动1」
  │  cmd_control { heightPreset1 }
  ▼
VEH ── response result=0 ──────────────▶ Qt
VEH ── post heightPreset1=1 ───────────▶ Qt（图标亮）
VEH ── CAN 0x31D BYTE1 bit0 = 1（下发 VCU）
  │  （保持 1000ms）
  ▼
VEH ── CAN 0x31D BYTE1 bit0 = 0（自动归零）
VEH ── post heightPreset1=0 ───────────▶ Qt（图标灭）
```

### 高度值写入（PDO）
```
Qt 写 pumpSettings.heightAddr1 = 3000
  │  cmd_control（单参数）
  ▼
VEH → VCU 写 + 等回显（异步）
  ├─ 成功：response result=0, data=回读值
  └─ 失败：response result=-6, data=旧值
           + post param_rollback（旧值，Qt 回滚）
```

## 6. 给 Qt 的对接清单（重点逐项）

- [ ] **启动1~5、停止**：按下时各发一次 `cmd_control`，**不发松开/结束命令**（满足需求「不带记忆 + 1s 自复位」由 VEH 实现）。
- [ ] **图标亮灭**：监听 `heightPreset1~5` / `heightPositioning` 的 post（1=亮，0=灭），**不要自己计时**。
- [ ] **一键水平** `oneTouchLeveling`：0/1 开关，状态从 500ms 全量推送读取。
- [ ] **一键水平停止设置** `horizontalStopSetting`：0/1 开关，VEH 持久化。
- [ ] **高度目标值**：`pumpSettings.heightAddr1~5` 走 query 读 / cmd_control 写（**写时单参数**）。
- [ ] **PDO 写失败**：处理 `result=-6` 和 `param_rollback` post，回滚 UI。
- [ ] 所有 request 必带 `msg_id`（UUID）。
- [ ] 注意 CAN 通道：需求图 CAN1 = 实际 CAN0。
