## 一、本次改了什么

**修复"手动选网锁死"**：设备被 `AT+COPS=1,2,<PLMN>` 手动锁定的运营商一旦失联，
注册会持续失败、且状态机回不到扫描/解锁 → 老固件会永久卡死在 `COPS:1`（现场
只能人工 `AT+COPS=0` 恢复）。本版新增自愈边：**FORCE_SIM 策略下注册连续失败满
5 分钟，自动 `AT+COPS=0` 回落自动选网，让模组重新搜网、另选可用运营商。**

同批附带的加固（不改变正常联网行为）：
- `wait_for_connect` 超时、非手动选网设备解开原注释的 `AT+COPS=0`（对齐上游）；该处选网超时 30s→60s。
- `stop_cfun`/`start_cfun` 成功路径补 `retry_nb=0`，消除跨状态重试计数误判。
- `cc_deque_get_at` 边界 `>`→`>=`（共享 EG25/IMX6ULL，收紧到文档契约，合法调用行为不变）。
- 补落盘日志：扫描候选运营商列表、选网失败原始应答；开机 `[INIT]` 落盘当前 COPS 模式。

> 不改 `is_oper_select` 默认值/语义，不改 L1/L2/L3 分级恢复。

## 二、测试重点

| # | 项目 | 期望 |
|---|---|---|
| 1 | **回归** | 正常拨号联网、断网自动重连、重启后自动联网，均不受影响 |
| 2 | **锁死自愈（核心）** | 人为把模组锁到一个当地绝对搜不到的运营商，重启 `modem_mng` 后，约 **5 分钟**内 SD 卡日志出现 `[REG TIMEOUT] ... forcing COPS=0`，随后自动重注册、恢复联网 |
| 3 | **恢复持久性** | 第 2 步恢复后 `reboot` / 断电重启，开机日志 `[INIT] COPS:` 应为自动（`+COPS: 0`），不再回到锁死 |

## 三、核心场景（第 2/3 项）操作步骤

> 目的：人为造出"锁定到一个注册不上的运营商"，验证 5 分钟后自愈。
> AT 通道设备节点为 `/dev/smd8`。

```sh
# 1) 停掉 modem_mng（若有看门狗自动拉起，拉起后再 kill 一次，确保手动操作时它不在跑）
killall modem_mng

# 2) 另开一路后台监听模组应答
cat /dev/smd8 &

# 3) 人为锁死到一个国内绝对搜不到的运营商
#    23415 = 英国 Vodafone，国内 100% 无覆盖；PLMN 合法，模组会接受但注册不上
#    可能要等 30~60s 才回 OK（正常现象）
echo -e 'AT+COPS=1,2,23415\r' > /dev/smd8

# 4) 确认已锁死
echo -e 'AT+COPS?\r' > /dev/smd8      # 期望 +COPS: 1（手动，大概率无运营商字段）
echo -e 'AT+CSQ\r'   > /dev/smd8      # 期望 +CSQ: 99,99（无信号/未注册）

# 5) 重启 modem_mng，让它自己发现锁死并触发恢复
modem_mng &     # 或按设备实际启动方式（看门狗/init）拉起

# 6) 盯日志，等约 300 秒
#    日志位置：/media/sdcard/dial_log/（已过 NTP 同步则在当天 YYYY-MM-DD/ 子目录）
#    期望依次看到：
#      [REG TIMEOUT] COPS not auto (+COPS: 1...), forcing COPS=0
#      [REG TIMEOUT] AT+COPS=0 rsp: OK
#      之后自动重注册、恢复联网（网络状态转好）
```

**通过判据**：满 5 分钟出现 `forcing COPS=0` → `AT+COPS=0 rsp: OK` → 恢复联网；
随后重启，`[INIT] COPS:` 显示为自动。

## 四、注意事项 / 验证边界（诚实标注）

- 本修复已在**国内测试机**上人为复现锁死并验证自愈通过（P1 PASS，含 reboot 后持久）；
  **海外真实现场（德国那台）未回归**——国内是"要么通要么绝对不通"的干净场景，
  可能未覆盖真实漫游下"时通时断"的灰度故障，建议有条件时在真实海外设备上跑一段观察。
- 仅影响 **FORCE_SIM（策略4）**；策略 1/2/3（Roamlink）路径的 COPS 由 Roamlink 自身处理，不受本改动影响。
- 已知设计局限：自愈按策略判定、**不区分"误锁 vs 有意锁定海外运营商"**；现网无有意锁定设备，暂按现状。
