## 一、项目总体结构

### 1.1 平台选择机制

`CMakeLists.txt` 根据环境变量 `QL_MODULE_PLATFORM` 设置编译宏：

| 环境变量 | 编译宏 | 主入口文件 |
|---|---|---|
| `EC200A` | `USE_EC200A_DIAL` | `dialer_ec200a.cpp` |
| `EG25G` | `USE_EG25_DIAL` | `dialer_eg25.c` |
| `MCIMX6Y2CVM08AB` | `USE_IMX6U_DIAL` | `dialer_imx6ull.cpp` |

三平台代码共存，编译时只选一套。`dialer.hpp` 定义纯虚接口，各平台实现：`startDialing / stopDialing / modem_init / create_call / start_call / stop_call / stop_cfun / start_cfun / dial_loop`。

### 1.2 进程线程模型

**EC200A：**
```
main()  (dialer_ec200a.cpp)
  ├─ log_init()
  ├─ wait_for_interface("ccinet0", 30s)   ── 阻塞直到网卡就绪
  ├─ create_cpactive() + cpactive_add_pinfo(timeout=60s, "modem_mng", "1.30")
  ├─ NanoReqHandler("tcp://127.0.0.1:38001")  → 独立线程 processModemRequests()
  ├─ publisher.init("tcp://127.0.0.1:48001")
  ├─ ConfigParser("/etc/config/config.json") 读 C020102 流量阈值
  ├─ signal(SIGINT/SIGTERM, signal_handler)
  ├─ std::thread dialThread(dial_loop)    ── 主拨号线程（所有核心逻辑）
  ├─ cv.wait_for(60s, isInterfaceSet)     ── 等 dialThread 首次 ping 成功回调
  │    → 超时：set_isExist(true) 触发 dial 线程退出
  │    → 成功：继续
  └─ TrafficMonitor::check_CCINet_FlowOverLimit()  ── 流量超限监控（阻塞）
       dialThread.join()
       log_close(); exit(0)
```

**EG25G：**
```
main()  (dialer_eg25.c)
  ├─ log_init()
  ├─ create_cpactive() + cpactive_add_pinfo(timeout=60s, "modem_mng", "1.33")
  ├─ g_at_port_mutex = PTHREAD_MUTEX_INITIALIZER  ── 全局AT口互斥锁（此文件）
  ├─ ConfigParser_create("/etc/config/config.json")
  ├─ startNanoReqHandler("tcp://127.0.0.1:38001")
  ├─ NetWork_EventPublisher_init("tcp://127.0.0.1:48001")
  ├─ dial_mng_new()           ── 分配状态结构体，探测Roamlink
  ├─ create_TrafficMonitor("")
  ├─ pthread_create(dial_task, p_dial_mng)  ── 主拨号线程
  └─ main线程 while(true) sleep(5):
       get_eg25_csq(handler) → nw_at_get_csq(smd_fd)  ── 每5s读CSQ
       CSQ < 20 持续5min → pub 208（低信号事件）
       CSQ > 25 持续5min → pub 209（信号恢复事件）
```

## 二、logger_sd 模块（`logger_sd.c`）

### 2.1 全局变量

```c
static FILE *g_log_fp = NULL;   // 日志文件句柄，NULL表示只输出控制台
```

### 2.2 `is_sdcard_mounted()`

逐行逻辑：
1. `fopen("/proc/mounts", "r")` — 打开内核虚拟文件，包含当前所有挂载点
2. 循环 `fscanf(fp, "%s %s %s %[^\n]", dev, mnt, fstype, rest)` — 逐行解析
3. 检查 `mnt == "/media/sdcard"` — 找到挂载点
4. 返回 1（已挂载）或 0（未挂载）

### 2.3 `check_sdcard_available()`（静态内部函数）

```
is_sdcard_mounted() == 0
  → system("echo 000 > /tmp/sdcard_avl")  ← 写标记文件供其他模块查询
  → return 0

statvfs("/media/sdcard", &stat)
  → 失败：return 0

free_bytes = stat.f_bavail * stat.f_frsize
free_mb = free_bytes / (1024*1024)
free_mb < 500
  → return 0

return 1
```

### 2.4 `log_init()`

```
if g_log_fp != NULL: return  ← 防重复初始化

check_sdcard_available() == 0
  → "Logging to console only" → return

system("mkdir -p /media/sdcard/dial_log")

time(&now); localtime(&now) → t

filename = "/media/sdcard/dial_log/dial_YYYYMMDD_HHMMSS.log"

g_log_fp = fopen(filename, "w")
  → 成功：写文件头 "=== Dial Program Started [时间] ===" + fflush
  → 失败：printf 错误信息（g_log_fp 仍为 NULL，后续只输出控制台）
```

### 2.5 `dial_log(fmt, ...)`

```
① 获取时间戳字符串 time_str = "YYYY-MM-DD HH:MM:SS"

② printf("[%s] ", time_str)
   va_start(args, fmt); vprintf(fmt, args); va_end(args)
   ← 输出到控制台（stdout）

③ if g_log_fp:
     fprintf(g_log_fp, "[%s] ", time_str)
     va_start(args, fmt); vfprintf(g_log_fp, fmt, args); va_end(args)
     fflush(g_log_fp)   ← 立即落盘，防掉电丢日志
```

**关键设计：** va_list 只能遍历一次，printf 用过后状态未定义，所以 fprintf 前必须重新 `va_start`。

### 2.6 `log_close()`

```
if g_log_fp:
  fprintf(g_log_fp, "=== Program Exit [时间] ===\n")
  fclose(g_log_fp)
  g_log_fp = NULL
```

## 三、dial_status 模块（`status/dial_status.c`）

### 3.1 全局变量

```c
static pthread_mutex_t g_status_mutex = PTHREAD_MUTEX_INITIALIZER;
```

### 3.2 辅助函数

**`dial_eg25_stat_name(int stat)`**  
EG25 拨号状态枚举 → 可读字符串，switch-case 映射 0~16：
```
0=none, 1=init, 2=sim_init, 3=sim_check, 4=sim_op,
5=reg_check, 6=cereg_check, 7=precondition_check, 8=pre_start_call,
9=start_call, 10=stop_call, 11=stop_cfun, 12=start_cfun,
13=list_oper, 14=select_oper, 15=wait_for_connect, 16=net_connected
```

**`dial_policy_name(int policy)`**  
1→PREFER_ROAMLINK, 2→PREFER_SIM, 3→FORCE_ROAMLINK, 4→FORCE_SIM

**`dial_get_rbmaster_pid()`**  
扫描 `/proc/<pid>/cmdline`，找包含 "RBMaster" 的进程，返回其 PID（整数）。未找到返回 0。注：此函数不做端口验证，可能返回僵尸进程 PID（仅用于状态文件展示，非存活判断）。

### 3.3 `dial_status_write(const dial_status_t *s)`

完整执行流程（每次心跳调用一次）：

```
① pthread_mutex_lock(&g_status_mutex)   ← 防多线程并发写

② fp = fopen("/tmp/dial_status.tmp", "w")
   → 失败：dial_log 错误 → unlock → return

③ time(&now); localtime_r(&now, &tm_buf); strftime → timebuf

④ 写注释头：
   "# dial status - auto generated by modem_mng vX.XX"
   "# updated: YYYY-MM-DD HH:MM:SS"

⑤ 写 [dial] section：
   version / uptime / state / policy / policy_name /
   channel / roamlink_available / license_pending / license_wait_sec

⑥ 写 [sim] section：
   iccid / csq / apn / profile_idx / plmn
   (plmn 来自 /tmp/network_plmn，由外部模块写入)

⑦ 写 [network] section：
   status / type
   if net_type == NETWORK_TYPE_SIM (1):
     ip = 实际IP地址（可能为 "0.0.0.0"）
     ifname = 实际网卡名
   else (Roamlink):
     ip = "n/a"
     ifname = "n/a"
   ← 设计意图：Roamlink通道激活时，IP/ifname属于物理SIM接口残留数据，写n/a避免误导

⑧ 写 [counters] section：
   tcp_fail_count / roamlink_fail_count / roamlink_rx_packets

⑨ 写 [roamlink] section：
   state / biz_no_data_sec / roamlink_connect_wait_sec / rbmaster_pid

⑩ 写 [stats] section：
   outage_count / last_outage_sec / total_outage_sec / current_outage_sec

⑪ fflush(fp); fclose(fp)

⑫ rename("/tmp/dial_status.tmp", "/tmp/dial_status")
   ← POSIX原子操作：读方永远读到完整文件

⑬ pthread_mutex_unlock(&g_status_mutex)
```

## 四、Roamlink 适配层（`roamlink_ec200a.c` / `roamlink_eg25.c`）

两个文件逻辑完全对称，差异只在 AT 命令发送方式：
- EC200A：`system("serial_atcmd AT+COPS=0")`，无需 `smd_fd`
- EG25：`Ql_SendAT(smd_fd, "AT+COPS=0", "OK", 5000, rsp_msg)` + `pthread_mutex_lock(&g_at_port_mutex)`

以下以 EC200A 为主说明，EG25 差异单独标注。

### 4.1 路径常量（来自头文件）

```c
ROAMLINK_MASTER_PATH   = "/usrdata/roamlink/RBMaster"
ROAMLINK_WORKDIR       = "/usrdata/roamlink"
ROAMLINK_CONF_PATH     = "/opt/conf.ini"
ROAMLINK_LICENSE_PATH  = "/usrdata/roamlink/etc/.pconfig/license.cer"
ROAMLINK_LICENSE_BACKUP_PATH = "/data/ufs/license.cer"
NET_POLICY_CONF_PATH   = "/usrdata/network.ini"
NETWORK_TYPE_PATH      = "/tmp/network_type"
ROAMLINK_CTRL_HOST     = "127.0.0.1"
ROAMLINK_CTRL_PORT     = 5568
ROAMLINK_CTRL_TIMEOUT_SEC = 5
ROAMLINK_CMD_START     = "RBstartServiceMaster"
ROAMLINK_CMD_STOP      = "RBstopServiceMaster"
ROAMLINK_CONNECT_TIMEOUT_SEC = 300   (EG25头文件中)
```

### 4.2 `probe()` — 四态探测

```
步骤1: access(ROAMLINK_MASTER_PATH, X_OK)
  失败 → return PROBE_NO_PACKAGE
         含义：设备未安装Roamlink包，永久降级到FORCE_SIM

步骤2: access(ROAMLINK_CONF_PATH, F_OK)
  失败 → return PROBE_CONF_MISSING
         含义：factoryApp尚未运行（conf.ini由factoryApp生成），等待

步骤3: stat(ROAMLINK_LICENSE_PATH, &st)
  失败 或 st.st_size == 0
       → return PROBE_LICENSE_MISSING
         含义：需要触发license下载流程，或从备份恢复

全部通过 → return PROBE_OK
```

**EG25专有：** `dial_mng_new()` 中若 `probe() == LICENSE_MISSING`，尝试调 `license_restore_from_backup()`，成功后再次调 `probe()` 验证。

### 4.3 `license_restore_from_backup()`

```
stat(ROAMLINK_LICENSE_BACKUP_PATH) 失败或为空 → return false

open(backup, O_RDONLY)
open(license_path, O_WRONLY|O_CREAT|O_TRUNC, 0644)

while read(src) > 0:
  write(dst)  ← 逐块4096字节复制

fsync(dst)  ← 确保写入磁盘
close(); return true
```

### 4.4 `license_appeared()` — 稳定性检测

```
stat(license_path) 失败或为空 → false

sleep(2)   ← 等2秒，防止RBMaster正在写

stat(license_path) 再次检查
  大小变化 → false（仍在写入）
  大小不变 → true（写完了）
```

### 4.5 `license_backup_and_reboot()` — 不返回

```
open(license, O_RDONLY)
open(backup_path, O_WRONLY|O_CREAT|O_TRUNC)
逐块复制 + fsync
close()
sync()      ← 全局同步所有文件系统
sleep(2)
reboot(RB_AUTOBOOT)  ← 系统重启，函数永不返回
while(1) sleep(1)    ← 保险，防止编译器优化
```

### 4.6 `read_policy()`

```
access(NET_POLICY_CONF_PATH, F_OK) 失败
  → return NET_POLICY_DEFAULT (4, FORCE_SIM)

iniparser_load(NET_POLICY_CONF_PATH)
  失败 → return NET_POLICY_DEFAULT

policy = iniparser_getint(ini, "network:network_select", NET_POLICY_DEFAULT)
iniparser_freedict(ini)

policy < 1 或 > 4
  → policy = NET_POLICY_DEFAULT  ← 值域校验

return policy
```

| 值 | 宏名 | 含义 |
|----|------|------|
| 1 | NET_POLICY_PREFER_ROAMLINK | 优先Roamlink，失败切SIM，SIM稳300s回切Roamlink |
| 2 | NET_POLICY_PREFER_SIM | 优先SIM，SIM断3min切Roamlink，Roamlink稳300s回切SIM |
| 3 | NET_POLICY_FORCE_ROAMLINK | 强制Roamlink，失败只重启服务不切SIM |
| 4 | NET_POLICY_FORCE_SIM | 永远SIM，不切换（默认值） |

### 4.7 `is_master_running()` — 双重检测

**原因：** 僵尸进程的 `/proc/<pid>/cmdline` 仍可读，单凭 `/proc` 扫描会误判。

```
步骤1: 扫描 /proc/*/cmdline
  opendir("/proc")
  while readdir:
    跳过非数字开头的目录（非进程目录）
    open(/proc/<pid>/cmdline, O_RDONLY)
    read → cmdline_buf
    strstr(cmdline_buf, "RBMaster") != NULL
      → proc_found = true; break

  proc_found == false → return false

步骤2: 验证端口5568连通性
  socket(AF_INET, SOCK_STREAM)
  fcntl(F_SETFL, O_NONBLOCK)   ← 非阻塞
  connect(127.0.0.1:5568)
    → 立即成功 (ret==0)：port_ok = true
    → EINPROGRESS：
        select(fd, timeout=1s)
          > 0: getsockopt(SO_ERROR) == 0 → port_ok = true
          <= 0: 超时/错误 → port_ok = false
    → 其他错误：port_ok = false

  socket()失败时：return true  ← 保守策略，避免反复fork

  port_ok == false
    → "RBMaster in /proc but port not reachable → likely zombie"
    → return false

return true
```

### 4.8 `start_master()` — 双 fork 无僵尸启动

```
is_master_running() == true
  → "already running, skip"; return

fork() → 子进程(pid>0) / 父进程(pid==pid_of_child)

子进程:
  fork() → 孙进程(grandchild==0) / 子进程(grandchild>0)
  
  孙进程(grandchild==0):
    chdir(ROAMLINK_WORKDIR)        ← RBMaster依赖相对路径加载.so
    devnull = open("/dev/null", O_WRONLY)
    dup2(devnull, STDOUT_FILENO)   ← 关闭孙进程的stdout
    dup2(devnull, STDERR_FILENO)   ← 关闭孙进程的stderr
    execl(ROAMLINK_MASTER_PATH, "RBMaster", NULL)
    _exit(1)  ← execl失败时退出
  
  子进程(grandchild>0):
    _exit(0)   ← 立即退出，孙进程成为孤儿

父进程:
  waitpid(pid, NULL, 0)  ← 等子进程退出，不产生僵尸
  sleep(3)               ← 等RBMaster完成初始化
```

**双fork的意义：**
- 父进程 fork 出子进程，子进程立即 fork 出孙进程后退出
- 孙进程的父进程（子进程）已退出，孙进程成为孤儿，由 init(PID=1) 接管
- 父进程只需 `waitpid` 子进程（子进程极快退出），不需要等孙进程（RBMaster可能一直运行）
- 结果：父进程不阻塞，孙进程不产生僵尸

### 4.9 `send_cmd(const char *cmd)` — TCP发命令

```
socket(AF_INET, SOCK_STREAM)  ← 创建TCP socket
fcntl(F_GETFL); fcntl(F_SETFL, flags | O_NONBLOCK)  ← 设置非阻塞

memset addr: family=AF_INET, port=5568, ip=127.0.0.1
connect(sockfd, addr)
  → 0: 立即连通，ok=true，跳到send标签
  → EINPROGRESS:
      FD_ZERO(&wfds); FD_SET(sockfd, &wfds)
      tv = {sec=ROAMLINK_CTRL_TIMEOUT_SEC(5), usec=0}
      select(sockfd+1, NULL, &wfds, NULL, &tv)
        → <= 0: 超时/错误 → goto done
        → > 0:
            getsockopt(SOL_SOCKET, SO_ERROR) == 0
              → ok=true
  → 其他错误: goto done

send标签:
  fcntl(F_SETFL, flags & ~O_NONBLOCK)  ← 切回阻塞模式
  send(sockfd, cmd, strlen(cmd), 0)
    → 失败: ok=false

done标签:
  close(sockfd)
  return ok
```

### 4.10 `mark_network_type(int type)`

```
snprintf(buf, "%d", type)
open(NETWORK_TYPE_PATH, O_WRONLY|O_CREAT|O_TRUNC, 0644)
write(fd, buf, len)   ← 不检查返回值（(void)write）
close(fd)
```

写入 `/tmp/network_type`：0=切换中，1=物理SIM，2=Roamlink。

### 4.11 `start_service()`

```
EC200A版本:
  send_at_cmd("at+cops=0")  → system("serial_atcmd at+cops=0")
  sleep(1)                   ← 给模组处理时间

EG25版本:
  pthread_mutex_lock(&g_at_port_mutex)
  Ql_SendAT(smd_fd, "AT+COPS=0", "OK", 5000, rsp_msg)
    失败: 记录日志，但继续（非致命错误）
    成功: 记录日志
  pthread_mutex_unlock(&g_at_port_mutex)

两平台共同:
  send_cmd(ROAMLINK_CMD_START)  ← "RBstartServiceMaster" → TCP到5568
    失败 → return false

  mark_network_type(NETWORK_TYPE_ROAMLINK)  ← 写/tmp/network_type=2
  return true
```

### 4.12 `stop_service()`

```
send_cmd(ROAMLINK_CMD_STOP)  ← "RBstopServiceMaster" → TCP到5568
  失败: 记录日志，但继续

mark_network_type(0)  ← 写/tmp/network_type=0

sleep(3)   ← 等模组完成注销，避免立刻重启物理SIM时状态混乱

return ok
```

## 五、EC200A 平台完整逻辑

### 5.1 辅助工具函数

#### `run_cmd(cmd, ...)` / `Ql_SendAT(atCmd)`
```c
Ql_SendAT("AT+COPS=0") → run_cmd("serial_atcmd AT+COPS=0") → system("serial_atcmd AT+COPS=0")
```
通过外部工具 `serial_atcmd` 发 AT 命令到模组串口，同步等待响应。

#### `get_csq_value_safe()`
```
fp = popen("serial_atcmd at+csq", "r")
while fgets(line, fp):
  p = strstr(line, "+CSQ:")
  if p:
    p += 5  ← 跳过"+CSQ:"
    sscanf(p, "%d", &rssi)  ← 读第一个数字（逗号前）
    break
pclose(fp)
return rssi  ← 0-31正常，99无信号，-1失败
```

#### `get_cereg_status_safe()`
```
fp = popen("serial_atcmd at+cereg?", "r")
while fgets(line, fp):
  p = strstr(line, "+CEREG:")
  if p:
    p = strchr(p, ',')  ← 找第一个逗号（格式: +CEREG: n,stat,...）
    p++
    status = atoi(p)    ← stat字段：1=已注册，5=漫游注册，3=被拒绝
    break
return status
```

#### `get_cpin_status_str(out_buf, len)`
```
fp = popen("serial_atcmd at+cpin?", "r")
默认填 "UNKNOWN"
while fgets(line, fp):
  p = strstr(line, "+CPIN: ")
  if p:
    p += 7  ← 跳过"+CPIN: "
    去除尾部\r\n
    strncpy(out_buf, p)
    break
pclose(fp)
```

返回值：`"READY"`（SIM正常）、`"SIM PIN"`（需要PIN）、`"SIM PUK"`、`"ERROR"`等。

#### `wait_for_interface(ifname, timeout_sec)`
```
while elapsed < timeout_sec:
  is_interface_present(ifname):
    socket(AF_INET, SOCK_DGRAM)
    ioctl(SIOCGIFINDEX, ifr)  ← 查网卡索引，不存在时返回-1
    close(sock)
    → 成功: return 1 (存在)
    → 失败: return 0 (不存在)
  
  存在: return 1
  不存在: 每2s打印一次等待日志; sleep(1); elapsed++

return 0  ← 超时
```

#### `check_and_update_retry_count()`
```
fp = fopen(RETRY_COUNT_FILE, "r")
  → 不存在 (fp==NULL): count = 0（首次启动）
  → 存在: fscanf读count，失败则count=0

count >= MAX_FAST_RETRY_TIMES (3):
  return -1   ← 进持久模式，不快速退出

count++
fp = fopen(RETRY_COUNT_FILE, "w")
fprintf(fp, "%d", count)
fflush(fp); fsync(fileno(fp)); fclose(fp)   ← 确保落盘

return count  ← 返回当前是第几次（1/2/3）
```

#### `clear_retry_count()`
```
access(RETRY_COUNT_FILE, F_OK) == 0
  → unlink(RETRY_COUNT_FILE)  ← 删文件
  → dial_log("Retry count cleared")
```

#### `restart_cfun_safe()`
```
count = read_cfun_count()    ← 读/tmp/cfun_count.txt，文件不存在返回0
count >= MAX_CFUN_CALLS (10) → return  ← 超10次，拒绝

uptime = get_system_uptime()  ← 读/proc/uptime浮点秒
last = read_last_call_time()  ← 读/tmp/cfun_last_call.txt
uptime - last < MIN_CFUN_INTERVAL (600) → return  ← 不足10分钟，拒绝

Ql_SendAT("AT+CFUN=0"); sleep(5); Ql_SendAT("AT+CFUN=1")

write_cfun_count(count + 1)  ← 写回次数
write_last_call_time(uptime) ← 写回时间
```

### 5.4 巡检主循环（50ms轮）

每轮开头（按顺序）：

```
① tnow = now_ms()
② cpactive_upt_atime(cpactive)    ← 喂看门狗，60s内必须调用
③ Fast Fail 检测
④ Roamlink 守护块
⑤ 心跳块（每30s）
⑥ switch(stage) 状态机
⑦ LED控制
⑧ usleep(50ms)
```

#### 5.4.1 Fast Fail 检测（每50ms）

```
if is_fast_fail_mode && !has_notified_connect:
  bool pdp_connected = (g_last_call_status == QL_NET_DATA_CALL_STATUS_CONNECTED)
  
  if pdp_connected:
    if pdp_ready_ts == 0:
      pdp_ready_ts = tnow
      dial_log("PDP connected, start Ping window (10000ms)")
    
    if tnow - pdp_ready_ts > FAST_FAIL_TIMEOUT_MS (10s):
      dial_log("Fast Fail: PDP up but no Ping success in 10s. Exiting...")
      log_close(); exit(1)
  
  else:  // PDP未建立
    pdp_ready_ts = 0   ← 重置，防止PDP断开重连后基准时间错误
    if tnow - start_loop_ts > PDP_WAIT_TIMEOUT_MS (60s):
      dial_log("Fast Fail: PDP not established in 60s. Exiting...")
      log_close(); exit(1)
```

**设计意图：** 旧逻辑从 `dial_loop` 入口计时，PDP建立本身耗时就可能耗尽10s窗口导致误判退出。新逻辑先等PDP建立（最多60s），PDP建立后才开始10s ping窗口。

#### 5.4.2 Roamlink 守护块（每50ms，优先级最高）

#### 5.4.4 状态机详解

状态流转：`ST_STATUS → ST_SIM → ST_SIGNAL → ST_PING → ST_STATUS`（循环）

每个状态执行完毕后设置 `stage = 下一状态`，下一轮50ms循环执行。

**ST_STATUS（每50ms）：**
```c
int st = g_last_call_status;   ← 读SDK异步回调更新的全局状态
// 当前实现：读取但未使用st，仅占位
stage = ST_SIM;
```

**ST_SIM（每800ms，由next_ts节流）：**
```
if tnow < next_ts: break   ← 节流
next_ts = tnow + SIM_INTERVAL_MS (800ms)

simStat = checkSimCardStatus()
  内部: popen("serial_atcmd at+cpin?") 读SIM状态 + CEREG注册状态
  返回: 0=SIM正常且已注册, 1=SIM异常, 2=未注册

simStat == 0: LOGI("SIM&Reg OK")

simStat == 1:
  if has_notified_connect:   ← 曾经连上，现在SIM断
    dial_log("[ERROR] SIM Card disconnected during runtime.")
    has_notified_connect = 0
    ping_fail_count = 0      ← 清jitter，下次从0开始计
  if start_fail_ts == 0: start_fail_ts = tnow  ← 开始故障计时

simStat == 2: LOGW("Network NOT registered")

stage = ST_SIGNAL
```

**ST_SIGNAL（每800ms）：**
```
if tnow < next_ts: break
next_ts = tnow + SIG_INTERVAL_MS (800ms)

rssi = get_csq_value_safe()
rssi < 0: LOGW("AT+CSQ no response")
0 <= rssi <= 31: LOGI("Signal RSSI=%d")
else: LOGW("Parse CSQ failed or no signal (RSSI=%d)")

stage = ST_PING
```

**ST_PING（每1500ms）：**

这是最重要的状态，包含所有通道切换逻辑。

```

next_ts = tnow + PING_INTERVAL_MS (1500ms)

bool ok = test_can_ping_google()
  → system("ping -c 1 8.8.8.8 > /dev/null") == 0
```

**Ping成功路径：**
```

   && roamlink_available
   && policy == PREFER_ROAMLINK
   && sim_fallback_ts > 0
   && (tnow - sim_fallback_ts) >= SIM_FALLBACK_RETRY_MS (300s):

  else:
    roamlink_fail_count++
    sim_fallback_ts = tnow   ← 失败：重置300s计时，稍后再试

        && roamlink_available
        && policy == PREFER_SIM
        && roamlink_fallback_ts > 0
        && (tnow - roamlink_fallback_ts) >= ROAMLINK_FALLBACK_RETRY_MS (300s):
  
  dial_log("Policy2: Roamlink stable Xs, trying SIM recovery")

  is_roamlink_active   = false

```

**Ping失败路径：**
```

  stage = ST_STATUS
  break   ← 静默：单次抖动不计故障

  start_fail_ts = tnow

uint64_t fail_duration = tnow - start_fail_ts

// ── SIM→Roamlink 切换触发 ──
if !is_roamlink_active               ← 当前在SIM
   && roamlink_available
   && (policy == PREFER_SIM
       || policy == PREFER_ROAMLINK)  ← 注意：FORCE_ROAMLINK不在此条件
   && fail_duration >= ROAMLINK_SWITCH_TIMEOUT_MS (3min):
  
  dial_log("policy=X: SIM down Xs, switching to Roamlink")
  ql_data_call_stop(g_call_id)
  sleep(2)
  roamlink_ec200a_start_master()
  
  if roamlink_ec200a_start_service():
    is_roamlink_active    = true
    roamlink_start_ts     = tnow
    roamlink_last_ping_ts = 0
    roamlink_fallback_ts  = tnow   ← 记录进入Roamlink时刻（策略2回切用）
    sim_fallback_ts       = 0
    start_fail_ts         = 0
    ping_fail_count       = 0
    dial_log("Switched to Roamlink channel")
  else:
    roamlink_fail_count++
    start_fail_ts = tnow   ← 重置，避免每1.5s重复触发切换
    dial_log("Switch failed")
  
  stage = ST_STATUS; break

// L1/L2/L3分级恢复：已被#if 0注释，不执行

stage = ST_STATUS
```

**EC200A ST_PING 切换条件说明：**  
FORCE_ROAMLINK 策略的 SIM→Roamlink 切换**不在 ST_PING**，而是在**启动时**（初始化段）就已激活 Roamlink。若启动失败（`is_roamlink_active=true` 但 `start_service` 失败），守护块会在300s后发现 `connect_timeout`，重启服务（FORCE_ROAMLINK 守护不切SIM）。

#### 6.3.3 Roamlink 初始启动（策略1/3）

#### 6.3.5 心跳块（每30s）详解

```
now = time(NULL)
if now - last_heartbeat < 30: 不执行

last_heartbeat = now

// ── 读取状态 ──
int sim_ok = nw_get_sim_card_status(h_nw_client) ? 1 : 0
int reg_ok = nw_reg_status_check(h_nw_client) ? 1 : 0
int csq = nw_at_get_csq(smd_fd)     ← AT+CSQ（持g_at_port_mutex）

// ── Ping检测 ──
bool net_ok = test_can_ping_google()

if net_ok:
  ping_fail_count = 0
  
  if start_fail_ts != 0:
    outage_dur = now - start_fail_ts
    dial_log("Network recovered after Xs")
    p_dial_mng->outage_count++
    p_dial_mng->last_outage_sec = outage_dur
    p_dial_mng->total_outage_sec += outage_dur
  start_fail_ts = 0
  
  if is_roamlink_active:
    roamlink_last_ping_ts = now   ← 更新Roamlink最近ping时间
  
  // ── 策略1回切（PREFER_ROAMLINK）──
  if !is_roamlink_active && roamlink_available
     && policy == PREFER_ROAMLINK
     && sim_fallback_ts > 0
     && (now - sim_fallback_ts) >= SIM_FALLBACK_RETRY_SEC (300):
    
    dial_log("Policy1: SIM stable Xs, trying Roamlink recovery")
    roamlink_eg25_start_master()
    if roamlink_eg25_start_service(smd_fd):
      is_roamlink_active = true
      roamlink_start_ts = now
      roamlink_last_ping_ts = 0
      sim_fallback_ts = 0
      start_fail_ts = 0
      ping_fail_count = 0
      dial_log("Switched back to Roamlink channel")
    else:
      roamlink_fail_count++
      sim_fallback_ts = now   ← 重置300s计时
      dial_log("Switch back failed, retry in 300s")
  
  // ── 策略2回切（PREFER_SIM）──
  else if is_roamlink_active && roamlink_available
          && policy == PREFER_SIM
          && roamlink_fallback_ts > 0
          && (now - roamlink_fallback_ts) >= ROAMLINK_FALLBACK_RETRY_SEC (300):
    
    dial_log("Policy2: Roamlink stable Xs, trying SIM recovery")
    roamlink_eg25_stop_service()
    is_roamlink_active = false
    roamlink_start_ts = 0
    roamlink_last_ping_ts = 0
    roamlink_fallback_ts = 0
    sim_fallback_ts = now
    ping_fail_count = 0
    p_dial_mng->is_func_called = true  ← 标记需要重新Init
    dail_start_data_call(p_dial_mng)   ← 启动SIM拨号
    dial_log("Switched back to SIM channel")

else:   // net_ok = false
  ping_fail_count++
  if ping_fail_count >= PING_FAIL_THRESHOLD (3) && start_fail_ts == 0:
    start_fail_ts = now
    dial_log("Ping failed 3 consecutive times, fault timer started")

// 计算断网时长
long downtime_sec = start_fail_ts > 0 ? (now - start_fail_ts) : 0

dial_log("[HEARTBEAT] SIM:%d | REG:%d | CSQ:%d | DownTime:%lds | PingFail:%d")

// ── Roamlink守护 ──
if is_roamlink_active:
  bool connect_timeout =
    (roamlink_last_ping_ts == 0
     && roamlink_start_ts != 0
     && (now - roamlink_start_ts) > ROAMLINK_CONNECT_TIMEOUT_SEC (300))
  
  bool fail_timeout =
    (roamlink_last_ping_ts != 0
     && (now - roamlink_last_ping_ts) > ROAMLINK_CONNECT_TIMEOUT_SEC (300))
  
  if connect_timeout || fail_timeout:
    roamlink_fail_count++
    
    if policy == PREFER_ROAMLINK || policy == PREFER_SIM:
      dial_log("[ROAMLINK] Channel failed, switching to SIM")
      roamlink_eg25_stop_service()
      is_roamlink_active = false
      roamlink_start_ts = 0
      roamlink_last_ping_ts = 0
      sim_fallback_ts = now
      roamlink_fallback_ts = 0
      ping_fail_count = 0
      dial_st = dial_stat_reg_check    ← 跳过init，直接从注册检查开始
      start_fail_ts = 0
    
    else:  // FORCE_ROAMLINK
      dial_log("[ROAMLINK] FORCE_ROAMLINK: channel timeout, restarting service")
      roamlink_eg25_stop_service(); sleep(5)
      roamlink_start_ts = now
      roamlink_last_ping_ts = 0
      roamlink_eg25_start_master()
      roamlink_eg25_start_service(smd_fd)

// ── SIM→Roamlink切换触发 ──
if !net_ok
   && start_fail_ts > 0
   && !is_roamlink_active
   && roamlink_available
   && (policy == PREFER_SIM || policy == PREFER_ROAMLINK || policy == FORCE_ROAMLINK)
   && downtime_sec >= ROAMLINK_SWITCH_TIMEOUT_SEC (180):
  
  dial_log("policy=X: SIM down Xs, switching to Roamlink")
  roamlink_eg25_start_master()
  
  if roamlink_eg25_start_service(smd_fd):
    is_roamlink_active = true
    roamlink_start_ts = now
    roamlink_last_ping_ts = 0
    roamlink_fallback_ts = now    ← 记录进入Roamlink时刻（策略2回切用）
    sim_fallback_ts = 0
    start_fail_ts = 0
    ping_fail_count = 0
    dial_log("Switched to Roamlink channel")
  else:
    roamlink_fail_count++
    start_fail_ts = now   ← 重置，避免立即重复触发
    dial_log("Switch failed")

// L1/L2/L3分级恢复：#if 0注释，不执行

// ── 写/tmp/dial_status ──
dial_status_write(&dstat)   ← 每次心跳原子写入状态文件
```

**EG25 vs EC200A 心跳块关键差异：**
- EG25 的 `state` 字段使用 `dial_eg25_stat_name(dial_st)` 映射状态机状态名
- EG25 的 IP 来自 `p_ipv4_data_call_info`（SDK返回），EC200A 来自 `ioctl(SIOCGIFADDR)`
- EG25 的 `net_status` 直接用 `net_ok`，EC200A 用 `(start_fail_ts==0 && has_notified_connect)`

#### 6.3.7 SIM 拨号状态机详解

**`dail_start_data_call(p_dial_mng)` 函数：**
```
if is_func_called (需要Init):
  QL_Data_Call_Init(dial_data_call_state_callback)
    成功: 继续
    失败: exit(0)  ← 严重失败，让守护拉起

if is_func_called (现在必为true，因为Init成功):
  data_call.profile_idx = profile_idx
  data_call.ip_family = QL_DATA_CALL_TYPE_IPV4
  data_call.reconnect = true  ← 自动重拨
  
  QL_Data_Call_Start(&data_call, &err)
    成功: is_func_called = false; return true
    失败: LOG_E; return false
    // 注：失败时is_func_called保持true，下次调用继续走Init+Start流程
```

**状态转移完整说明：**

```

  → dial_stat_init

dial_stat_init:
  QL_MCM_NW_Client_Init(&h_nw_client)   ← 初始化Qualcomm网络客户端
    失败: modem_need_reset=true (无实际效果); 下轮重试
  sim_op(SIM_OP_INIT, NULL)             ← SIM初始化

    失败:

  成功: → dial_stat_reg_check
  失败: modem_need_reset=true

dial_stat_reg_check:

  成功: → dial_stat_cereg_check
  失败: modem_need_reset=true; sleep(2)

dial_stat_cereg_check:
  nw_at_get_cereg_stat(smd_fd)   ← AT+CEREG? 增强型注册检查
  成功: → dial_stat_precondition_check
  失败: modem_need_reset=true; sleep(10)   ← 较长等待

dial_stat_precondition_check:
  QL_Data_Call_Init_Precondition()   ← Qualcomm SDK前置验证
  成功:
    profile_idx = -1   ← 重置，触发APN重新查询
    → dial_stat_pre_start_call
  失败: modem_need_reset=true

dial_stat_pre_start_call:
  if profile_idx == -1:   ← 需要分配profile
    if p_apn_obj == NULL:
      p_apn_obj = apn_get_apn_obj(sim_iccid)   ← 按ICCID查APN数据库
    
    if p_apn_obj != NULL:
      profile_idx = apn_scan_idx(p_apn_obj)    ← 获取可用profile索引
    
    // 注意：此状态不转移，下一轮继续进来
    // 当 profile_idx != -1 时进入else分支
  
  else:   ← profile_idx 已分配
    modem_need_reset = true  ← 设置但无实际效果
    QL_Data_Call_Set_Default_Profile(&profile)
    → dial_stat_start_call

dial_stat_start_call:
  dail_start_data_call(p_dial_mng)   ← 见上方函数说明
  成功:
    → dial_stat_wait_for_connect
    dial_timer = cur_timer   ← 记录连接等待超时起点

dial_stat_wait_for_connect:
  nw_get_connect_state(profile_idx) == 1
    → 连上:
        get_tz_after_connected(p_dial_mng)     ← AT+QLTS=1 读时区（仅执行一次）
        ipv4_data_call_info_init(p_dial_mng)
          ← nw_get_connect_ipv4_data_call_info(profile_idx) 获取IP/DNS/GW
          ← nw_get_ifaddrs(ip) 获取网卡名
        nw_mark_network_status(1)   ← 写/tmp/network_status=1
        set_net_status(p_dial_mng, 1)
        → dial_stat_net_connected
    
    → 未连上:
        modem_need_reset = true  (无实际效果)
        dif_timer = cur_timer - dial_timer
        if dif_timer.tv_sec > DIAL_TIMEOUT_SECONDS (120):
          if p_apn_obj->is_oper_select:
            → dial_stat_list_oper   ← 漫游运营商，需要手动选网
          else:
            → dial_stat_reg_check   ← 普通超时，重新注册

dial_stat_net_connected:
  LEDControl_controlLight(handle, ledId, 1)   ← 亮灯
  
  nw_get_connect_state(profile_idx) <= 0:
    "connection lost"
    set_net_status(0); nw_mark_network_status(0)
    → dial_stat_reg_check
  
  else:   ← 保持连接
    // 监控RX包数（流量watchdog）
    nw_get_if_statistics_rx_packets(&if_rx_packets, ifa_name)
    if if_rx_packets > u64_if_rx_packets:
      u64_if_rx_packets = if_rx_packets
      dial_timer = cur_timer   ← 有新包，重置超时计时
    
    dif_timer = cur_timer - dial_timer
    if dif_timer.tv_sec > DIAL_TIMEOUT_SECONDS (120):
      "no data rx on net if, redial"
      → dial_stat_reg_check   ← 120s无新包，认为网络异常，重新拨号
  
  sleep(5)   ← 此状态每5s检查一次（其他状态每1s）

dial_stat_list_oper:
  if deque_oper为空:
    Ql_SendAT(smd_fd, "AT+COPS=?", "OK", 180000ms, rsp_msg)
    ← 最多等180s扫描可用运营商
    失败: retry_nb++; >= AT_RETRY_NB(2) → retry_nb=0, → dial_stat_reg_check
          sleep(5); continue
    成功: parse_oper_list_info(deque_oper, rsp_msg)
    ← 解析 "+COPS: (2,"CHN-UNICOM","UNICOM","46001",2),..."
    ← 只把 stat==1(可用) 的运营商PLMN加入队列
  
  if deque_oper非空:
    → dial_stat_select_oper
  else:
    → dial_stat_reg_check

dial_stat_select_oper:
  deque_oper队首取 p_oper (PLMN字符串，如"46001")
  sprintf(str, "AT+COPS=1,2,%s", p_oper)   ← 手动选网
  Ql_SendAT(smd_fd, str, "OK", 30000ms, rsp_msg)
  
  失败:
    retry_nb++
    if retry_nb >= AT_RETRY_NB (2):
      retry_nb = 0
      dial_log("Remove operator %s after retry failure")
      cc_deque_remove_first(deque_oper, &p_oper); free(p_oper)   ← 删此运营商
      if deque_oper为空: → dial_stat_start_cfun   ← 所有运营商都试过了
      else: → dial_stat_list_oper  ← 还有运营商，继续
    usleep(5s); continue
  
  成功:
    cc_deque_remove_first(deque_oper, &p_oper); free(p_oper)
    → dial_stat_stop_cfun   ← 选网后做CFUN重置

dial_stat_stop_cfun:
  Ql_SendAT(smd_fd, "AT+CFUN=0", "OK", 15000ms, rsp_msg)
  ← 关闭射频
  失败: retry_nb++; >= 2 → retry_nb=0, → dial_stat_reg_check
       usleep(5s); continue
  成功: usleep(5s); → dial_stat_start_cfun

dial_stat_start_cfun:
  Ql_SendAT(smd_fd, "AT+CFUN=1", "OK", 15000ms, rsp_msg)
  ← 打开射频
  失败: retry_nb++; >= 2 → retry_nb=0, → dial_stat_reg_check

  成功: usleep(5s); → dial_stat_sim_init   ← 从SIM初始化重新开始
```

## 十一、EC200A Fast Fail 机制详解

**目的：** 4G链路临时异常（如SDK服务未启动）时快速退出，让init/watchdog重启进程，而不是无限卡死等待。

**三次机会原则：** 前3次尝试用快速失败模式，第4次进入持久模式永不退出。这样即使有临时异常，3次重启尝试内能恢复；如果连续3次都失败，说明是系统性问题，持久模式不再退出避免重启风暴。

```
启动时:
  count = 0 (无文件) 或 文件中的值
  count >= 3 → return -1 → is_fast_fail_mode=false（持久模式）
  count < 3  → count+1写回 → return count → is_fast_fail_mode=true

运行时(每50ms):
  if is_fast_fail_mode && !has_notified_connect:
    
    PDP断开:
      pdp_ready_ts = 0
      tnow - start_loop_ts > 60s → exit(1)
    
    PDP已连:
      首次连接: pdp_ready_ts = tnow
      tnow - pdp_ready_ts > 10s → exit(1)

首次ping成功:
  unlink(/tmp/dial_retry_count)   ← 清计数
  is_fast_fail_mode = false       ← 解除快速失败

重启场景举例:
  第1次: count=1写入, is_fast_fail=true
    → 60s无PDP → exit(1)
  init重启
  第2次: count=2写入, is_fast_fail=true
    → PDP通，10s无ping → exit(1)
  init重启
  第3次: count=3写入，但此时3 >= MAX(3) → return -1 → is_fast_fail=false
  → 进持久模式，不再exit(1)
```

## 十七、EG25 AT模块（`eg25/at/at.c`）

### 17.1 总体设计

EG25 的 AT 通信通过 `/dev/ttyUSB2`（`QUEC_AT_PORT` 宏定义）进行，使用标准 POSIX 文件 I/O + `select()` 超时模式，不依赖任何私有 SDK 接口。模块对外暴露两个函数：`at_init()` 和 `Ql_SendAT()`。

### 17.2 `at_init()` — AT 端口初始化

```c
int at_init(void) {
    static int smd_fd = -1;       // 静态局部变量：整个进程只打开一次
    if (smd_fd >= 0) return smd_fd;  // 已初始化，直接返回缓存的 fd

    smd_fd = open(QUEC_AT_PORT, O_RDWR | O_NONBLOCK | O_NOCTTY);
    if (smd_fd < 0) return smd_fd;  // 打开失败返回负值

    Ql_SendAT(smd_fd, "ATE0", "OK", 1000, NULL);  // 关闭回显
    Ql_SendAT(smd_fd, "AT",   "OK", 1000, NULL);  // 基础握手
    Ql_SendAT(smd_fd, "ATI",  "OK", 1000, NULL);  // 模块信息
    return smd_fd;
}
```

**关键设计点：**
- `static int smd_fd = -1`：静态局部变量，第一次调用时初始化，后续调用直接返回已缓存的 fd。整个进程生命周期内 AT 端口只开一次。
- `O_NONBLOCK`：非阻塞打开，配合后续 `select()` 实现超时等待。
- `O_NOCTTY`：防止 AT 端口成为进程的控制终端，避免信号干扰。
- 初始化序列：`ATE0` 关闭模块回显（防止后续解析干扰），`AT` 验证通信，`ATI` 读取模块信息。

**被调用方式：** `nanomsg_process.cpp` 中 EG25 的 `getImei()` 和 `getOperatorName()` 直接调用 `at_init()` 获取 fd，然后传入 `Ql_SendAT()`，无需关心端口是否已经打开。

### 17.3 `Ql_SendAT()` — AT 命令收发

```
int Ql_SendAT(int smd_fd, char *atCmd, char *finalRsp, long timeout_ms, char *p_rsp_msg)
```

| 参数 | 含义 |
|------|------|
| `smd_fd` | AT 端口文件描述符（由 `at_init()` 返回） |
| `atCmd` | AT 命令字符串，例如 `"AT+CSQ"` |
| `finalRsp` | 期望的终止响应字符串，例如 `"OK"` |
| `timeout_ms` | 超时时间（毫秒） |
| `p_rsp_msg` | 输出缓冲区（可为 NULL），用于接收完整响应内容 |

**返回值：** `0`=收到 finalRsp；`1`=超时；`-1`=select 错误。

**执行流程：**

```
1. 构建 AT 命令字符串（strncpy），末尾补 "\r\n"（若原命令无换行）
2. read(smd_fd, ...) 清空端口残留数据（非阻塞读，清除之前未读的 URC）
3. write(smd_fd, strAT, iLen)  ← 发送 AT 命令
4. while(1) {
     select(smd_fd+1, fds, NULL, NULL, &timeout)  ← 等待可读或超时
     case -1: return -1  ← 系统错误
     case  0: return  1  ← 超时
     default:
       do {
         read(smd_fd, strResponse, AT_MSG_LENGTH_MAX)
         if strstr(strResponse, "\r\n{finalRsp}")
             || strstr(..., "+CME ERROR:")
             || strstr(..., "+CMS ERROR:")
             || strstr(..., "ERROR")
           → 拷贝到 p_rsp_msg，bRcvFinalRsp = TRUE
         usleep(10000)  ← 10ms 小延迟，等待后续数据
       } while (rdLen > 0 && rdLen == AT_MSG_LENGTH_MAX)  ← 继续读直到缓冲区未满
   if (bRcvFinalRsp) break
}
5. return 0
```

**设计细节：**
- `timeout` 结构体在 `select()` 调用后被修改（Linux 行为），while 循环不重置 timeout，实际上实现的是"总超时"而非"每次读的超时"。即如果第一次 select 等待了 900ms，第二次只剩 100ms。
- `strFinalRsp` 拼接为 `"\r\n{finalRsp}"`（加前缀），匹配 AT 响应的标准格式。
- `p_rsp_msg` 只拷贝最后一次成功匹配的响应块，适合单行响应（`+CSQ: ...`）。若响应分多次 read，只保留最后一块。

**调用点：**
- `nw_at_get_csq()`：`AT+CSQ` 查询信号强度
- `nw_at_get_cereg_stat()`：`AT+CEREG?` 查询 LTE 注册状态
- `roamlink_eg25.c`：`AT+COPS=0` 触发自动运营商选择
- `nanomsg_process.cpp`：`AT+CGSN` 获取 IMEI，`AT+COPS?` 获取运营商名称

## 十八、EG25 网络模块（`eg25/nw/nw.c`）

### 18.1 模块职责

`nw.c` 封装了所有与网络状态查询相关的底层操作，分为三类：
1. **MCM API 调用**：`QL_MCM_SIM_GetCardStatus()`、`QL_MCM_NW_GetRegStatus()` 等通过 MCM 框架与 modem 通信
2. **Data Call API 调用**：`QL_Data_Call_Info_Get()` 等通过 WWAN 框架查询 PDP 状态
3. **AT 命令查询**：`AT+CSQ`、`AT+CEREG?` 通过串口 AT 端口查询信号/注册状态

### 18.2 函数详解

#### `nw_get_sim_card_status(nw_client_handle_type nw_client)` → `bool`

```c
QL_MCM_SIM_CARD_STATUS_INFO_T t_info = {0};
QL_MCM_SIM_GetCardStatus(nw_client, E_QL_MCM_SIM_SLOT_ID_1, &t_info);
sim_card_app_status = t_info.card_app_info.app_3gpp.app_state - 0xB00;
return (sim_card_app_status == SIM_CARD_READY);
```

- SIM 卡应用状态码是 MCM 枚举值偏移 `0xB00` 之后的序号，`SIM_CARD_READY` 即就绪态。
- 硬编码使用 `E_QL_MCM_SIM_SLOT_ID_1`（SIM 卡槽1），EG25 不支持双物理 SIM。

#### `nw_reg_status_check(nw_client_handle_type nw_client)` → `bool`

```c
QL_MCM_NW_GetRegStatus(nw_client, &t_info);
return t_info.data_registration_valid;
```

- `data_registration_valid` 是 MCM 返回的"数据注册是否有效"标志，与 CS 语音注册独立。
- 调用方（`dial_task()`）在 `reg_check` 状态下轮询此函数，数据注册成功才进入下一状态。

#### `nw_mark_plmn(char *mcc, char *mnc)`

```c
sprintf(echo_cmd, "echo %s%s > %s", mcc, mnc, NW_PLMN_PATH);
system(echo_cmd);
```

- `NW_PLMN_PATH` = `/tmp/network_plmn`，写入 MCC+MNC 合并字符串（例如 `"46000"`）。
- 用 `system()` + shell echo 写文件，不直接调用 `open()/write()`。

#### `nw_at_get_csq(int smd_fd)` → `int`（CSQ 值，失败返回 -1）

```c
static int pre_csq = -1;  // 静态变量：上次 CSQ 值，避免重复写文件
pthread_mutex_lock(&g_at_port_mutex);
Ql_SendAT(smd_fd, "AT+CSQ", "OK", 1000, rsp_msg);
pthread_mutex_unlock(&g_at_port_mutex);
// sscanf(p_csq, "+CSQ: %d,%d", &csq, &ber)
if (pre_csq != csq) {
    // 先检查/创建文件，再 system("echo %d > /tmp/network_csq")
    pre_csq = csq;
}
return csq;
```

- `g_at_port_mutex`：外部声明（定义在 `dialer_eg25.c`），防止 AT 端口被多线程并发使用（主拨号线程和 nanomsg 查询线程可能同时调用）。
- `pre_csq` 静态变量：只有 CSQ 变化时才写文件，减少文件 I/O。
- 写 `/tmp/network_csq` 也用 `system("echo")`，而非直接文件写入。

#### `nw_mark_network_status(int net_status)`

```c
fd = open(NW_STATUS_PATH, O_WRONLY | O_CREAT);
write(fd, br_str, strlen(br_str));
close(fd);
```

- `NW_STATUS_PATH` = `/tmp/network_status`，写 `"0"` 或 `"1"`。
- 注意：无 `O_TRUNC` 标志，若文件已存在且写入字符串更短，旧内容可能残留（实际上 `"0"` 和 `"1"` 都是1字节，不成问题）。

#### `nw_set_default_profile(int profile_idx)`

```c
QL_Data_Call_Get_Default_Profile(&profile);
if (profile.profile_idx != profile_idx) {
    profile.profile_idx = profile_idx;
    QL_Data_Call_Set_Default_Profile(&profile);
}
```

- 只在需要时修改，避免不必要的 SDK 调用。在 `dial_task()` 的 `pre_start_call` 阶段调用，设置本次拨号使用的 APN profile。

#### `nw_get_connect_state(int profile_idx)` → `int`（1=连接，0=断开，-1=查询失败）

```c
QL_Data_Call_Info_Get(profile_idx, QL_DATA_CALL_TYPE_IPV4, &data_call_info, &err);
ret = (QL_DATA_CALL_CONNECTED == data_call_info.v4.state) ? 1 : 0;
nw_mark_network_status(ret);  // 同步写 /tmp/network_status
```

- 每次调用都同步更新 `/tmp/network_status`，不等待回调。

#### `nw_get_connect_ipv4_data_call_info(int profile_idx)` → `ql_data_call_info_s*`（调用方负责 free）

```c
p_data_call_info = calloc(1, sizeof(ql_data_call_info_s));
QL_Data_Call_Info_Get(profile_idx, QL_DATA_CALL_TYPE_IPV4, p_data_call_info, &err);
return p_data_call_info;  // 失败时 free 并返回 NULL
```

- 返回完整的数据呼叫信息（IP地址、DNS、MTU等），调用方需自行 free。

#### `nw_data_call_valid()` → `int`（0=就绪，-1=超时）

```c
int retry = 10;
while (0 != QL_Data_Call_Init_Precondition() && retry--) {
    usleep(500 * 1000);
}
return (retry != 0) ? 0 : -1;
```

- 在真正发起 data call 之前调用，确认 modem 的 data call 子系统就绪（最多等 5 秒）。

#### `nw_get_network_info()` — 调试用，打印所有网络接口信息

遍历 `getifaddrs()` 结果，对 AF_INET/AF_INET6 打印 IP，对 AF_PACKET 打印 rx/tx 包数。仅用于调试，生产代码不调用。

#### `nw_get_ifaddrs(char *p_ip_addr)` → `struct ifaddrs*`（调用方负责 free）

```c
getifaddrs(&ifaddr);
for ifa in ifaddr:
    getnameinfo(ifa->ifa_addr, ..., host, ...)
    if strncmp(p_ip_addr, host, strlen(p_ip_addr)) == 0:
        p_ifaddrs = calloc + memcpy(ifa)
        break
freeifaddrs(ifaddr)
return p_ifaddrs  // 找不到返回 NULL（未初始化，实际可能返回随机值）
```

- **注意潜在 bug**：若未找到匹配，`p_ifaddrs` 未赋值直接返回（未初始化指针），调用方需检查前须先初始化为 NULL。
- 调用方通过已知的 IP 地址反查接口名（`ifa_name`），用于后续读取 `/sys/class/net/<if>/statistics/`。

#### `nw_get_if_statistics_rx_packets(uint64_t *p_rx_packets, char *if_name)` → `bool`

```c
sprintf(path, NW_IF_STATISTICS_RX_PACKETS_PATH, if_name);
// 展开为 "/sys/class/net/%s/statistics/rx_packets"
open(path, O_RDONLY);
lseek(fd, 0L, SEEK_END);  // 获取文件大小
lseek(fd, 0L, SEEK_SET);
read(fd, val_bytes, file_size);
*p_rx_packets = strtoull(val_bytes, NULL, 0);
```

- 读取 sysfs 接口计数器，用于流量统计，而非 MCM/AT 查询。

#### `nw_at_get_cereg_stat(int smd_fd)` → `bool`

```c
pthread_mutex_lock(&g_at_port_mutex);
Ql_SendAT(smd_fd, "AT+CEREG?    ", "OK", 1000, rsp_msg);  // 注意：命令后有空格
pthread_mutex_unlock(&g_at_port_mutex);
sscanf(p_cereg, "+CEREG: %d,%d", &cereg_n, &stat_cereg);
return (stat_cereg == 1) || (stat_cereg == 5);
```

- `stat_cereg == 1`：已注册本网（home network）
- `stat_cereg == 5`：已注册漫游网
- AT 命令后有多余空格 `"AT+CEREG?    "`，但模块会忽略尾部空格，功能正常。

## 十九、APN 数据库模块（两平台）

### 19.1 APN JSON 文件格式

文件路径：`/usr/dial/apn.json`（`APN_JSON_NAME` 宏）

```json
{
  "apn": [
    {
      "supplier": "中国移动",
      "iccid": "8986011",
      "apn": "cmnet",
      "usrname": "",
      "pwd": "",
      "is_oper_select": false,
      "oper": ["46000", "46002", "46007"]
    },
    {
      "supplier": "中国联通",
      "iccid": "8986031",
      "apn": "3gnet",
      "usrname": "",
      "pwd": ""
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `supplier` | string | 运营商名称（仅供参考，不用于匹配） |
| `iccid` | string | **ICCID 前缀**，用于 `strncmp` 前缀匹配 |
| `apn` | string | PDP APN 名称 |
| `usrname` / `pwd` | string | 认证用户名/密码（可为空字符串） |
| `is_oper_select` | bool | 是否需要手动选择运营商（EG25 特有） |
| `oper` | string[] | PLMN 列表，`is_oper_select=true` 时有效（EG25 特有） |

**ICCID 前缀匹配逻辑：** `strncmp(p_list[i].iccid, iccid, strlen(p_list[i].iccid))` — 以 JSON 中的 iccid 字段长度为准，只比较前 N 位，实际 ICCID（20位）只需匹配前缀。

### 19.2 EC200A APN 模块（`ec200a/apn/apn.c`）

#### `apn_load_from_json(char *json_path, int *p_apn_count)` → `apn_obj_t*`

使用 **json-c** 库（`json_tokener_parse()`，`json_object_object_get_ex()`）解析 JSON，将所有条目加载为 `apn_obj_t` 数组并返回（堆分配，调用方 free）。

解析字段：`apn`、`iccid`、`usrname`、`pwd`（不含 `is_oper_select` 和 `oper`，EC200A 无运营商选择功能）。

注意：代码中有 `json_object_put(json_temp)` 调用，但 `json_object_object_get_ex()` 返回的对象引用计数不应由调用方 put，这是原始代码的轻微错误，实际中通常不影响（json-c 处理得比较宽松）。

#### `apn_get_apn_obj(char *iccid)` → `apn_obj_t*`（调用方 free）

```c
p_list = apn_load_from_json("/usr/dial/apn.json", &apn_count);
for i in p_list:
    if strncmp(p_list[i].iccid, iccid, strlen(p_list[i].iccid)) == 0:
        p_result = malloc + memcpy(p_list[i])
        free(p_list)
        return p_result
free(p_list)
// 未找到：返回 calloc 空对象（apn/iccid 均为空字符串）
p_result = calloc(1, sizeof(apn_obj_t))
return p_result
```

- 找到时返回匹配项的独立副本；未找到时返回全零空对象（相当于"使用默认APN"）。
- `dialer_ec200a.cpp` 调用此函数获取 APN，再调用 `ql_data_call_set_apn_config(DATA_CALL_APN_PUBLIC, &cfg)` 设置。

#### `set_apn(char *iccid)` — EC200A 中直接调用 SDK 设置 APN

与 `apn_get_apn_obj()` 类似，但直接在函数内调用 `ql_data_call_set_apn_config(DATA_CALL_APN_PUBLIC, &apn_cfg)`，不返回对象。若未找到 ICCID，使用 `APN_NAME_PUBLIC` 默认 APN（空字符串）。

### 19.3 EG25 APN 模块（`eg25/apn/apn.c`）

EG25 的 APN 流程更复杂，因为 EG25 使用 Qualcomm OE 的 `QL_APN_*` API 管理 modem 内部的 APN profile 列表，而不是每次直接传入 APN 配置。

#### `apn_scan_from_json(char *json_path, char *iccid)` → `apn_obj_t*`

使用 **cJSON** 库（`cJSON_Parse()`，`cJSON_GetObjectItem()` 等），比 EC200A 使用的 json-c 更轻量。

与 EC200A 的 `apn_load_from_json()` 区别：
- **cJSON vs json-c**：接口不同，结果等价
- **额外字段**：解析 `is_oper_select`（bool）和 `oper`（字符串数组）
- **`deque_apn_oper`**：当 `oper` 字段存在且为数组时，将每个 PLMN 字符串 `calloc+memcpy` 后加入 `cc_deque`（双端队列）
- **`is_oper_select` 默认为 true**：若 JSON 中无此字段，默认设 true（表示需要手动选择运营商）；只有明确写 `false` 才不选

```c
json_temp = cJSON_GetObjectItem(json_apn, "is_oper_select");
p_apn_obj->is_oper_select = true;  // 默认 true
if ((json_temp != NULL) && (cJSON_IsBool(json_temp))) {
    p_apn_obj->is_oper_select = cJSON_IsTrue(json_temp);
}
```

#### `apn_get_apn_obj(char *iccid)` — EG25 版本

```c
p_apn_obj = apn_scan_from_json(json_path, iccid);
if (p_apn_obj == NULL) {
    // 未找到：返回空 apn_obj_t（等效默认APN）
    p_apn_obj = calloc(1, sizeof(apn_obj_t));
    memcpy(p_apn_obj, &cnst_default_apn, sizeof(cnst_default_apn));
}
return p_apn_obj;
```

- EG25 版 `cnst_default_apn` 初始化为 `{"", "", "", "", NULL}`（含 `deque_apn_oper = NULL`）。

#### `apn_add(apn_obj_t *p_apn_obj)` → `int`（profile_idx，失败 -1）

```c
memset(&apn, 0, sizeof(ql_apn_add_s));
apn.pdp_type = QL_APN_PDP_TYPE_IPV4;
strncpy(apn.apn_name, p_apn_obj->apn, ...);
strncpy(apn.username, p_apn_obj->usr_name, ...);
strncpy(apn.password, p_apn_obj->pwd, ...);
QL_APN_Add(&apn, &profile_idx);
return profile_idx;
```

向 modem 内部 APN 列表添加一条新 profile，返回分配的 `profile_idx`。

#### `delete_apn_profile()` — 清空所有 APN profile

```c
while (true) {
    QL_APN_Get_Lists(&apn_list);
    if (apn_list.cnt == 0) break;
    for i in apn_list.cnt:
        QL_APN_Del(i);
    usleep(100000);
}
```

循环删除直到列表为空（因为删除后 idx 可能重排，重新 Get 再删最安全）。

#### `apn_scan_idx(apn_obj_t *p_apn_obj)` → `int`（profile_idx）

```
QL_APN_Get_Lists(&apn_list)
if cnt == 0:
    → apn_add(p_apn_obj)   // 空列表，直接添加
else:
    for i in apn_list:
        if strcmp(p_apn_obj->apn, apn_list.apn[i].apn_name) == 0:
            break  // 找到匹配
    if 找到:
        return apn_list.apn[i].profile_idx  // 返回现有 idx
    else:
        for i: QL_APN_Del(i)  // 删除所有不匹配的 profile
        → apn_add(p_apn_obj)  // 重新添加目标 APN
```

**设计意图：** 确保 modem 内部 APN 配置与 JSON 文件同步，同时尽量复用已有 profile（避免不必要的删除+重建）。

#### `apn_get_idx(char *iccid)` → `int`（profile_idx）— 完整 APN 流程

```
p_apn_obj = apn_load_from_json(json_path, &apn_obj_count)
for i in p_apn_obj:
    if strncmp(iccid_prefix) match:
        apn_profile_idx = apn_scan_idx(&p_apn_obj[i])
        break
if not found:
    apn_profile_idx = apn_scan_idx(default_empty_apn)
return apn_profile_idx
```

- 这是 `dial_task()` 在 `sim_op` 阶段调用的入口函数，完成从 ICCID 到 modem profile_idx 的完整映射。

### 19.4 两平台 APN 处理对比

| 方面 | EC200A | EG25 |
|------|--------|------|
| JSON解析库 | json-c | cJSON |
| 设置方式 | `ql_data_call_set_apn_config()` 直接设 | `QL_APN_Add/Del/Get_Lists` 管理 profile 列表 |
| 返回值 | `apn_obj_t*`（APN 对象） | `int`（profile_idx） |
| 运营商选择 | 无 | 支持 `is_oper_select` + `deque_apn_oper` |
| 默认 APN | 空字符串对象 | 空 `cnst_default_apn` |
| 调用入口 | `apn_get_apn_obj(iccid)` | `apn_get_idx(iccid)` |

### 20.1 EC200A SIM 模块（`ec200a/sim/sim.c`）

EC200A 使用私有 SDK `ql_sim_*` API 操作 SIM 卡。

#### `sim_init()` / `sim_deinit()`

```c
ql_sim_init()   // 初始化 SIM 子系统
ql_sim_deinit() // 反初始化
```

简单包装，加了错误日志。

#### `sim_get_imsi(char *imsi)` — 获取 IMSI

```c
slot = QL_SIM_SLOT_1;          // 硬编码 SIM 卡槽 1
app_type = QL_SIM_APP_TYPE_UNKNOWN;  // 硬编码 app 类型（从 input=0 分支）
```


#### 调用位置

### 20.2 EG25 SIM 模块（`eg25/sim/sim.c`）

EG25 使用 MCM API（`QL_MCM_SIM_*`），需要维护一个 `sim_client_handle_type h_sim`（静态全局变量）。

#### `sim_op(int cmdIdx, char *buf)` — 低级分发函数

```c
switch (cmdIdx) {
case 0 (SIM_OP_INIT):    QL_MCM_SIM_Client_Init(&h_sim)
case 1 (SIM_OP_DEINIT):  QL_MCM_SIM_Client_Deinit(h_sim)
case 2 (SIM_OP_GET_IMSI):
    t_info.e_slot_id = E_QL_MCM_SIM_SLOT_ID_1;
    t_info.e_app = E_QL_MCM_SIM_APP_TYPE_3GPP;
    QL_MCM_SIM_GetIMSI(h_sim, &t_info, buf, SIM_BUF_SIZE)
case 3 (SIM_OP_GET_ICCID):
    QL_MCM_SIM_GetICCID(h_sim, E_QL_MCM_SIM_SLOT_ID_1, buf, SIM_BUF_SIZE)
}
```

`SIM_BUF_SIZE`、`SIM_OP_*` 宏在 `sim.h` 中定义。

#### `sim_process(char *buf_iccid, char *buf_imsi)` — 带重试的批量读取

```c
// 读 ICCID（最多 20 次重试，每次间隔 100ms，共最长 2s）
while (E_QL_OK != sim_op(SIM_OP_GET_ICCID, buf_iccid)):
    usleep(100000); if retry-- <= 0: return -1
// 读 IMSI（同样重试逻辑）
while (E_QL_OK != sim_op(SIM_OP_GET_IMSI, buf_imsi)):
    usleep(100000); if retry-- <= 0: return -1
```

- `dial_task()` 在 `sim_op` 状态下调用，将 ICCID 和 IMSI 存入 `p_dial_mng->sim_iccid` 和 `sim_imsi`。
- `SIM_OP_DEINIT` 的调用被注释掉（不反初始化，保持 handle 有效）。

#### `sim_deinit()` — 带重试的反初始化

```c
int retry = 10;
while (E_QL_OK != sim_op(SIM_OP_DEINIT, NULL) && retry--):
    usleep(100000);
```

## 二十一、nanomsg IPC 模块（`nanomsg_process.cpp`）

### 21.1 架构概述

nanomsg IPC 模块实现两个角色：
- **`ModemReqHandler`**：纯数据采集类，各平台实现 IMEI/IMSI/ICCID/CSQ/APN 等字段的读取
- **`NanoReqHandler`**：nanomsg REQ/REP socket 服务，监听 `tcp://127.0.0.1:38001`，收到请求后调用 `ModemReqHandler::getStatus()` 组 JSON 响应

### 21.2 `ModemReqHandler::getStatus()` — 主状态包组装

```
getStatus():
    getCCINetStats(rxBytes, txBytes, net_interface)  // 从 sysfs 读流量
    getDns()                                          // 从 /etc/resolv.conf 读 DNS
    
    cellular = cJSON_CreateObject()
    // 填充字段：model, md_sw_ver, md_hw_ver（平台条件编译）
    // IMEI: getImei() → EC200A: serial_atcmd; EG25: Ql_SendAT(AT+CGSN)+regex
    // IMSI: getImsi() → EC200A: serial_atcmd; EG25: QL_MCM_SIM_GetIMSI
    // ICCID: getIccid() → EC200A: iccid成员变量; EG25: QL_MCM_SIM_GetICCID
    // LAC/CI: getCellInfo() → EC200A: serial_atcmd AT+CREG?; EG25: 硬编码 "0","5"
    // CSQ: getCsq() → EC200A: serial_atcmd AT+CSQ; EG25: 读 /tmp/network_csq
    // roaming: isRoaming() → EC200A: AT+CREG stat==5; EG25: 恒 false
    // IP: get4gIp() → ip addr show <net_interface>，提取 "inet x.x.x.x/"
    // DNS: dns1/dns2（getDns() 填充）
    // gateway: changeLastOctetToOne(ip_4g)
    // APN: getApn()
    // TX/RX: TrafficMonitor(net_interface).get_history_*()
    
    return cJSON_Print(cellular)
```

**缓存策略（EG25）：**
- `getImsi()`：`static std::string cached_imsi`，首次成功后永久缓存（不刷新）
- `getIccid()`：同上，`static std::string cached_iccid`
- `getImei()`：同上，`static std::string cached_imei`
- `getOperatorName()`：`static` 缓存 + `REFRESH_INTERVAL_SEC=60`（60秒刷新一次，通过 AT+COPS?）

**平台差异表：**

| 字段 | EC200A | EG25 | IMX6ULL |
|------|--------|------|---------|
| IMEI | `serial_atcmd at+cgsn` | `Ql_SendAT(AT+CGSN)`+regex | `Imx6uDialer::imei` |
| IMSI | `serial_atcmd at+cimi` | `QL_MCM_SIM_GetIMSI` | `Imx6uDialer::imsi` |
| ICCID | 成员变量 `iccid` | `QL_MCM_SIM_GetICCID` | `Imx6uDialer::iccid` |
| CSQ | `serial_atcmd at+csq` | 读 `/tmp/network_csq` | `Imx6uDialer::get_csq()` |
| 运营商 | `serial_atcmd at+cops?`（PLMN匹配） | `Ql_SendAT(AT+COPS?)`（字符串提取） | `Imx6uDialer::operatorName` |
| LAC/CI | `serial_atcmd at+creg?` | 硬编码 "0","5" | — |
| 漫游 | AT+CREG stat==5 | 恒 false | — |
| APN | `serial_atcmd AT+CGDCONT?`+regex | 硬编码 `"eg25_develop"` | `Imx6uDialer::get_apn()` |

### 21.3 辅助方法

#### `runCommand(const char *cmd)` → `std::string`

```cpp
popen(cmd, "r") → fgets 循环读取所有输出 → pclose
```

捕获命令所有输出（含多行），EC200A 大量使用此函数调用 `serial_atcmd`。

#### `runCommandAndGetFirstLine(const char *cmd)` → `std::string`（第一行）

同上，但截取到第一个 `\n` 为止。

#### `getCellInfo(std::string &lac, std::string &ci)` — 两平台实现不同

- EC200A：执行 `serial_atcmd at+creg?` 得到 `+CREG: 3,1,"271a","0d176547",7`，用 `getLac()`/`getCi()` 提取引号间字符串
- EG25/IMX6：硬编码 `lac="0"`, `ci="5"`（待实现）

#### `getLac()` / `getCi()` — 字符串提取

从 AT+CREG 响应中提取 LAC（第1对引号之间）和 CI（第2对引号之间），用 `find('"')` 定位。

#### `isConnectedToInternet()` → `bool`

```cpp
sock = socket(AF_INET, SOCK_STREAM, 0);
sa.sin_port = htons(53);     // DNS 端口 53
inet_pton(AF_INET, "8.8.8.8", &sa.sin_addr);
connect(sock, &sa, sizeof(sa));  // TCP connect（不发数据，只检查路由）
```

通过 TCP connect 到 8.8.8.8:53 检测互联网连通性（不依赖 ICMP）。

#### `getDns()` → `std::string`

读取 `/etc/resolv.conf`，提取所有 `nameserver` 行，存入 `dns1`/`dns2`，处理行尾 `# comment` 和空行。未找到时默认 `"8.8.8.8"`。

#### `getCCINetStats()` — 接口流量统计

```cpp
basePath = "/sys/class/net/"
遍历 basePath 下所有目录，找 name.startswith(net_interface) 的接口
读 rx_bytes / tx_bytes 文件
```

`net_interface` 是通过 WWAN SDK 获取的接口前缀（如 `"ccinet"` 或 `"rmnet"`）。

### 21.4 `NanoReqHandler::processModemRequests()` — nanomsg 服务主循环

```
while (!isExit) {
    req_bytes = nn_recv(sock, &req_msg, NN_MSG, 0)  // 阻塞等待请求
    if req_bytes < 0:
        retries++
        if retries >= max_retries(10):
            initialize_connection(sock, url)  // 重新绑定/连接
            retries = 0
        sleep(1); continue
    
    request = cJSON_Parse(req_msg)
    nn_freemsg(req_msg)
    
    ts = request["ts"]           // 请求时间戳
    status = request["status"]
    network = status["network"]  // 数组
    
    for item in network:
        if item.find("cellular") != npos:
            ret_str = modemReqHandlerPtr->getStatus()
            // 构建响应 JSON: {ts, status:{network:{cellular: ...}}}
            nn_send(sock, out, strlen(out)+1, 0)
            break
    
    cJSON_Delete(request)
}
```

**请求格式：**
```json
{"ts": 1234567890, "status": {"network": ["cellular"]}}
```

**响应格式：**
```json
{
  "ts": 1234567890,
  "status": {
    "network": {
      "cellular": {
        "model": "...", "imei": "...", "imsi": "...", "iccid": "...",
        "csq": 20, "ip": "10.x.x.x", "dns1": "...", "dns2": "...",
        "network_online": 1, "tx": 1024, "rx": 2048, ...
      }
    }
  }
}
```

**错误重连：** `nn_recv` 连续失败 10 次后，调用 `initialize_connection()` 重建 socket 绑定，重置重试计数。每 5 次失败打印一次错误。

### 21.5 端口与 URL

| 用途 | URL | 模式 |
|------|-----|------|
| 状态查询 REP | `tcp://127.0.0.1:38001` | REQ/REP |
| 网络事件 PUB | `tcp://127.0.0.1:48001` | PUB/SUB |

### 23.2 `data_call_status_ind_cb()` — EC200A 核心连接状态回调

这是 EC200A 最重要的回调，由 SDK 在连接状态变化时异步调用。

```c

                             QL_NET_DATA_CALL_STATUS_E pre_call_status,
                             ql_data_call_status_t *p_msg)
```

**执行流程（CONNECTED 分支）：**

```
g_last_call_status = p_msg->call_status   // 更新全局状态（供 dial_loop() 的 ST_STATUS 读取）

if CONNECTED:
    system("echo 0 > /tmp/dial_Status")   // 连接状态文件
    system("echo 1 > /tmp/network_status")

    is_valid_ifname(p_msg->device) → strncpy(g_if_name, p_msg->device)  // 校验后保存接口名

    if has_addr (IPv4):

        system("cat /tmp/resolv_v4.conf >> /etc/resolv.conf")
        if /tmp/resolv_v6.conf exists: cat 追加

    if has_addr6 (IPv6):

        system("ip -6 ro add default via <gateway6> dev <if>")
        写 /tmp/resolv_v6.conf 并合并到 /etc/resolv.conf

if DISCONNECTED:
    system("echo 1 > /tmp/dial_Status")
    system("echo 0 > /tmp/network_status")
```

**设计要点：**
- IPv4 和 IPv6 路由/DNS 各自独立配置（`resolv_v4.conf` / `resolv_v6.conf`）

## 二十四、故障上报模块（`fault_report/`）

### 24.1 NetworkMonitor — 网络连通性监控

```cpp
// 策略模式：NetworkChecker 抽象基类，PingNetworkChecker 是具体实现
class PingNetworkChecker : public NetworkChecker {
    bool checkNetwork():
        executeCommand("ping -c 1 8.8.8.8")
        return output.find("1 packets transmitted, 1 received") != npos
};

class NetworkMonitor {
    std::thread monitoringThread;
    bool networkDown;
    time_t networkDownStartTime;
    
    monitorLoop():
        while !stopFlag:
            isUp = networkChecker->checkNetwork()
            monitorNetwork(isUp)
            sleep_for(5s)
    
    monitorNetwork(isUp):
        lock_guard<mutex> lock(mtx)
        if !isUp:
            if !networkDown:
                networkDown = true; networkDownStartTime = now
            elif now - networkDownStartTime >= 600:  // 10分钟
                pub("NETWORK", "Unable to establish 4G connection", 210)
        else:
            if networkDown:
                pub("NETWORK", "4G Network connection recovered", 211)
            networkDown = false
```

- 每 5 秒 ping 一次，持续断网 **10 分钟**才发布事件 210（避免短暂中断误报）
- 恢复时立即发布事件 211
- `NetWork_EventPublisher::getInstance().pub()` 通过 nanomsg PUB socket 广播

## 二十五、重启配置模块（`reboot_conf/dial_reboot_conf.c`）

### 25.1 功能概述

持久化"是否已执行过重启"的标志，防止因持续断网导致无限重启循环。仅在前置条件满足时（信号强度 > 20、SIM 卡正常、ql_netd 运行）才执行重启。

### 25.2 全局配置结构体 `Config g_config`

| 字段 | 含义 |
|------|------|
| `uptime` | 程序启动时的系统 uptime（秒）|
| `restart_flag` | 是否已重启过（0=未重启，1=已重启）|
| `first_disconnect` | 首次断网标志（运行时，不持久化）|
| `signal_strength` | 当前 CSQ 信号强度 |
| `sim_status` | SIM 卡状态（0=正常，-1=异常）|
| `ql_netd_status` | ql_netd 进程状态（0=运行中）|

### 25.3 主要函数

#### `read_config()` / `write_config()`

配置文件 `CONFIG_FILE`（`/tmp/dial_reboot_conf` 或类似路径），格式：`uptime,restart_flag`。

- `read_config()`：若文件不存在则初始化并写入（记录当前 uptime，restart_flag=0）
- `write_config()`：`fprintf(file, "%d,%d\n", uptime, restart_flag)`

#### `get_uptime()` → `int`

读 `/proc/uptime`，`fscanf("%f", &uptime)`，返回整数部分。

#### `check_sim_status()` — 两平台实现

- EC200A：`sim_init()` + `sim_get_iccid()` → `g_config.sim_status = ret`
- EG25：`nw_get_sim_card_status(p_dial_mng->h_nw_client)` → `g_config.sim_status = 0/-1`

#### `check_pre_conditions()` → `int`

```c
g_config.signal_strength = get_signal_csq();  // popen("serial_atcmd at+csq")
return (csq > 20) && (sim_status >= 0) && (ql_netd_status == 0);
```

前置条件全部满足才允许执行重启，防止在无信号/无SIM/服务未就绪时重启。

#### `handle_dial_up_down()` — 重启决策逻辑

```
check_pre_conditions() → 不满足则跳过

if restart_flag == 1: return  // 已重启过，本次开机不再重启

if restart_flag == 0:
    current_uptime = get_uptime()
    if current_uptime - g_config.uptime > THRESHOLD_TIME:
        restart_flag = 1
        write_config()    // 先持久化，防止重启后重新执行
        perform_reboot()  // 写 REBOOT_FILE + sleep(10) + system("reboot")
```

- `THRESHOLD_TIME`：重启阈值（秒），从宏定义（通常 300s-600s）
- `REBOOT_FILE`：写入 `"1\n"` 作为重启信号文件，sleep 10s 后执行 `system("reboot")`
- 先写 `restart_flag=1` 再重启：重启后读取到 1，不再触发第二次重启

## 二十六、cc_deque 双端队列库（`cc_deque/cc_deque.c`）

### 26.1 来源与用途

来源：Collections-C 开源库（LGPL），版本截取。本项目用于 EG25 `apn_obj_t.deque_apn_oper`，存储 APN 对应的运营商 PLMN 列表（如 `["46000","46002","46007"]`）。

### 26.2 数据结构

```c
struct cc_deque_s {
    size_t   size;       // 当前元素个数
    size_t   capacity;   // 缓冲区容量（始终为 2 的幂）
    size_t   first;      // 头指针索引（环形）
    size_t   last;       // 尾指针索引（环形，指向下一个写入位置）
    void   **buffer;     // 元素指针数组
    // mem_alloc / mem_calloc / mem_free 可自定义分配器
};
```

**环形缓冲区设计：** 所有索引运算用 `& (capacity-1)` 代替取模，要求 capacity 必须是 2 的幂（`upper_pow_two()` 保证）。

### 26.3 关键操作

| 操作 | 复杂度 | 说明 |
|------|-------|------|
| `cc_deque_new()` | O(1) | 初始容量 DEFAULT_CAPACITY=8 |
| `cc_deque_add_last()` | O(1) 摊销 | 追加到队尾，满时 `expand_capacity()` 翻倍 |
| `cc_deque_add_first()` | O(1) 摊销 | 插入队头，`first = (first-1) & (cap-1)` |
| `cc_deque_add_at(index)` | O(n) | 用 memmove 处理跨越环形边界的情况 |
| `cc_deque_remove_first/last` | O(1) | 只移动指针，不移动数据 |
| `cc_deque_get_at(index)` | O(1) | `i = (first + index) & (cap-1)` |
| `cc_deque_trim_capacity()` | O(n) | 缩容到 `upper_pow_two(size)`，重新线性化 |
| `cc_deque_reverse()` | O(n/2) | 双指针对调 |

### 26.4 扩容机制

```c
expand_capacity():
    new_capacity = capacity << 1   // 翻倍
    new_buffer = calloc(new_capacity, sizeof(void*))
    copy_buffer(deque, new_buffer, NULL)  // 重新线性化（消除环绕）
    first = 0; last = size
```

copy_buffer 时消除环形绕圈：`last > first` 则一次 memcpy；否则分两段（先 `[first..cap-1]`，再 `[0..last-1]`）。

### 26.5 本项目使用方式

```c
// eg25/apn/apn.c: apn_scan_from_json()
cc_deque_new(&p_apn_obj->deque_apn_oper);
// 对 oper 数组每个 PLMN 字符串：
p_oper_name = calloc(1, strlen + 1);
memcpy(p_oper_name, p_json_str, strlen);
cc_deque_add_last(p_apn_obj->deque_apn_oper, p_oper_name);
```

存储 PLMN 字符串的拷贝，供运营商选择逻辑（`is_oper_select=true`）遍历时使用。

### 27.1 功能

### 27.2 `parse_tz_info(char *p_tz_str, int *p_tz)` → `bool`

```
// 解析格式：+QLTS: "2023/12/05,09:43:17+32,0"
//           时区偏移 = +32，表示 UTC+8（偏移量以15分钟为单位：32×15min=480min=UTC+8）

if strstr(p_tz_str, "+QLTS:"):
    找第一个 '"'，找第二个 '"'
    提取引号间内容到 tz_str
    sscanf(p_start, "%*d/%*d/%*d,%*d:%*d:%*d%d,%*d", p_tz)  // 跳过日期时间，直接读时区偏移
```

`%*d` 是 scanf 的跳过模式，读取但不存储整数。`+32` 对应东八区（中国标准时间）。

### 27.3 `save_tz_info(int tz)`

```
// 路径: TZ_SAVE_PATH = "/usr/dial/tz_info.ini"
```

#### 30.3.2 `test_can_ping_google()` — 改进版 ping 检测

```cpp
bool test_can_ping_google() {
    popen("ping -c 1 -W 2 8.8.8.8 2>/dev/null", "r")
    逐行 fgets → strstr(line, "ttl=") || strstr(line, "TTL=")
    pclose()（忽略返回值）
    return is_success
}
```

**设计要点：** 使用 `popen` 读输出内容而非 `system()` 返回值。原因：SIGCHLD 信号处理函数（`ql-sdk` 内部注册）会消费子进程退出状态，导致 `system()` 返回 -1 假阴性。改用读取输出流中的 `ttl=` 字段作为成功标志，免疫信号干扰。

相比之下，`Imx6uDialer::test_can_ping_google()` 仍用 `system()` 返回值（该平台无 SDK 信号干扰，不受此问题影响）。

#### 30.3.3 `parseTimezone()` — HTTP Date 时区解析（EC200ADialer 版）

用于解析 HTTP 响应头中的日期时间字段（如 `"Mon, 16 Jun 2025 11:10:35 +0800"`）：

```
1. find_last_of(' ') → 取最后一个空格后的 5 字符（"+0800"）
2. 验证 [0] 为 '+'/'-'，[1][2] 为数字
3. hour = stoi(substr(1,2))  →  8
4. sign = (tz_part[0]=='+') ? 1 : -1
5. tz = sign * hour * 4      →  32
   (15分钟单位，与 QLTS 响应中的时区编码兼容)
```

#### 30.3.4 `saveTimezone(tz)` — 时区持久化

存储路径：`/usr/dial/tz.ini`，格式 `[dev]\ntz = 32`。

流程：
1. 若文件不存在 → `mkdir -p /usr/dial` → 创建含默认值 `tz=32` 的文件
2. `iniparser_load` → `iniparser_getint("dev:tz", 255)`
3. 若旧值 ≠ 新值 → `iniparser_set("dev:tz", new_val)` → `iniparser_dump_ini` → `sync()`
4. 只在值变化时写文件（减少 flash 磨损）

#### 30.3.5 `checkDialAttemptTime()` — 2 分钟拨号保护

防止 `restart_cfun_safe()`（RF reset）过于频繁触发：

```
文件: /tmp/dial_attempt_time.txt
阈值: TIME_DIFF_THRESHOLD = 120s

1. stat(FILENAME) 不存在 → writeCurrentTimeToFile() → 返回 0（允许）
2. 文件存在 → 读取记录时间戳
3. diff > 120s → 更新文件 → 返回 1（允许操作）
4. diff ≤ 120s → 返回 0（拒绝，距上次操作不足 2 分钟）
```

调用方检查返回值，返回 1 才触发 CFUN 复位。

#### 30.3.6 `data_call_status_ind_cb()` — SDK 回调（注册在类内，静态方法）

### 30.4 `Imx6uDialer` 类

#### 30.4.1 AT 命令发送核心

```cpp
static std::string sendATCommand(cmd, serialPortPath):
    fd = open(serialPortPath, O_RDWR|O_NOCTTY|O_NDELAY)
    fcntl(fd, F_SETFL, FNDELAY)    ← 非阻塞模式
    write(fd, cmd)
    select(fd+1, &read_fds, NULL, NULL, {5s, 0})
    逐次 read(fd, buffer) 直到无数据 → response += buffer
    close(fd)
    return response
```

重载版本 `sendATCommand(cmd, path, timeoutSec)` 允许自定义超时（不局限于 5s）。

#### 30.4.2 `adapterAT(serialPortPath, timeoutSeconds)` — AT 就绪探测

```
循环发送 "ATE0\r\n"：
- 响应含 "OK" 且不含 "ERROR" → return true
- 否则 elapsedSeconds += 2; sleep(2)
- elapsedSeconds >= timeoutSeconds → return false（超时）
```

用于检测 modem 是否已初始化就绪，避免在 modem 启动期发送 AT 命令失败。

| `get_iccid(port)` | `AT+QCCID` | 找 `"QCCID:"` + `regex("\d+")` → `iccid` |
| `get_csq(port)` | `AT+CSQ` | 找 `"+CSQ:"` + `regex("\d+")` → `csq` (int) |

#### 30.4.6 `Imx6uDialer::parseTimezone()` — QLTS 格式解析

```
响应格式：+QLTS: "2023/12/05,09:43:17+32,0"
1. find('"') → 找到内容字符串
2. sscanf(tz_str, "%*d/%*d/%*d,%*d:%*d:%*d%d,%*d", &parsed_tz)
   ← 跳过日期时间部分，直接提取 +32
3. tz = parsed_tz（已是 15 分钟单位，不需要 ×4）
```

与 `EC200ADialer` 版本不同：EC200A 解析 HTTP Date 头（小时 ×4），iMX6 解析 QLTS AT 响应（直接读偏移值）。

---

### 30.5 设计总结

| 特性 | `EC200ADialer` | `Imx6uDialer` |
|------|---------------|---------------|
| SDK 接入方式 | Quectel C SDK | AT 命令（串口） |
| ping 检测 | popen+ttl（抗信号干扰） | system() 返回值 |
| 时区来源 | HTTP Date 头（hour×4） | QLTS AT（直接偏移） |
| GPIO 控制 | sysfs（GPIO 130/128） | 同上 |
| AT 串口 | SDK 接管，不直接操作 | `/dev/ttyUSB0`（直接 read/write） |
| USB 检测 | 无（SDK 已处理） | `isVendorPresent()` + `lsusb` |

### 31.3 核心函数

#### `read_network_conf(config_file_path)`

```c
dictionary *ini = iniparser_load("/opt/conf.ini");
config.network_select = iniparser_getint(ini, "network:network_select", 4);
// 4 为错误默认值
```

读取 `/opt/conf.ini` 中 `[network]` 段的 `network_select` 键：
- `1` → SIM 拨号
- `2` → Roamlink 拨号
- `4` → 无效配置（视为 SIM 兜底）

#### `start_roamlink()` / `stop_roamlink()`

```c
system("echo 'RBstartServiceMaster' | nc 127.0.0.1 5568");
system("echo 'RBstopServiceMaster'  | nc 127.0.0.1 5568");
```

通过 TCP Socket 向 RBMaster 守护进程（监听 5568 端口）发送控制命令，启动或停止 Roamlink 服务。

#### `change_dial_status(p_dial_mng, new_status)`

```c
pthread_mutex_lock(&p_dial_mng->mutex);
p_dial_mng->should_dial = new_status;
pthread_cond_signal(&p_dial_mng->cond);
pthread_mutex_unlock(&p_dial_mng->mutex);
```

通过 mutex + condvar 向拨号主线程发信号，控制 SIM 拨号的启/停（`should_dial=true` → 开始 SIM 拨号，`false` → 停止）。

#### `dial_via_sim()` / `dial_via_roamlink()`

```c
dial_via_sim():
    stop_roamlink()           ← 先停 Roamlink
    sleep(1)
    change_dial_status(ptr_dial_mng, true)   ← 触发 SIM 拨号

dial_via_roamlink():
    change_dial_status(ptr_dial_mng, false)  ← 先停 SIM
    sleep(1)
    start_roamlink()          ← 启动 Roamlink
```

两者互为对偶操作，确保切换时先停旧通道再起新通道，`sleep(1)` 等待旧通道实际断开。

### 31.4 决策逻辑（`main_test()`）

`main_test()` 是策略选择的完整演示，决策树如下：

```
检查 /opt/conf.ini     → 不存在 → 使用 SIM
检查 license.cer       → 不存在 → 使用 SIM
  ↓（两者均存在）
read_network_conf:
    network_select == 1 → 使用 SIM
    network_select == 2 → 使用 Roamlink
  ↓
perform_dial() 失败 → 自动切换到另一种策略

主循环（SWITCH_INTERVAL=600s）：
    can_ping("8.8.8.8"):
        成功 → 记录 last_success_time
               若目标是 Roamlink 且证书存在 且 启动后 <600s → 切换到 Roamlink
        失败 → prev_status 从成功→失败 OR 超过 600s 未成功
               → 切换到另一种策略 + perform_dial()
    sleep(CHECK_INTERVAL=10)
```

**证书路径：** `/usrdata/roamlink/etc/.pconfig/license.cer`
**配置路径：** `/opt/conf.ini`

- `main()` 入口（该平台编译为独立可执行文件时使用）

---

### 32.2 状态机 (`dial_loop()`)

iMX6ULL 平台采用明确的枚举状态机，状态定义在 `dialer.hpp` 中：

```
POWER_ON → CONFIGURE_USB → WRITE_TO_MODEM → CONFIGURE_NETWORK
    → CHECK_CONNECTION ↔ SUCCESS
    ↓（失败）
LIST_OPERATOR → SELECT_OPERATOR → WRITE_TO_MODEM（循环）
    ↓（彻底失败）
FAILURE_RETRY → POWER_ON（重启）
```

#### 状态详解

| 状态 | 操作 |
|------|------|
| `POWER_ON` | `powerOnModule()`（GPIO 130/128 上下电序列）→ `CONFIGURE_USB`；`brctl delif bridge0 usb0`（防止 usb0 混入网桥） |
| `CONFIGURE_USB` | `configureUSBModule()`：写 `/sys/bus/usb-serial/drivers/option1/new_id`，检查 `/dev/ttyUSB0`；失败重试最多 10 次，否则回 `POWER_ON` |
| `WRITE_TO_MODEM` | `ATE0`（关回显）→ `AT+QCFG="usbnet",1`（网卡模式）→ `AT+QNETDEVCTL=3,1,1`（启动拨号）→ `CONFIGURE_NETWORK` |
| `CONFIGURE_NETWORK` | `killall -9 udhcpc` + 检测 `ifconfig -a` 中 `usb0` 是否出现（重试 5 次×2s）；找到后 `udhcpc -i usb0 &`（DHCP 获取 IP），sleep 5s → `CHECK_CONNECTION` |
| `CHECK_CONNECTION` | `ifconfig usb0` 检查 IP → `test_can_ping_google()`；成功 → LED 亮 → `SUCCESS`；连续 5 次失败 → `LIST_OPERATOR` |
| `SUCCESS` | `dev_name = "usb0"`，`interface_name = dev_name`，`callback()`（通知主线程网卡就绪），sleep 10s → `CHECK_CONNECTION`（持续监控） |
| `LIST_OPERATOR` | 有历史运营商名 → 直接尝试用旧 PLMN 重注册；否则 `AT+COPS=?`（扫描，180s 超时）→ 解析运营商列表到 `deque_oper`，重试 3 次 → `SELECT_OPERATOR` |
| `SELECT_OPERATOR` | 从 `deque_oper` 取第一个 PLMN → `AT+CFUN=0` → `AT+CFUN=1` → `AT+COPS=1,2,<plmn>,7`（强制注册）→ 确认 `AT+COPS?` → `WRITE_TO_MODEM`；失败 → 继续下一个 PLMN |
| `FAILURE_RETRY` | `rm /tmp/dial_success` + sleep 2s → `POWER_ON` |

---

### 32.3 启动优化

```cpp
// 开机检测：曾经拨号成功过吗？
stat("/tmp/modem_started") == 0 → running_before = true

if (test_can_ping_google()):
    system("touch /tmp/dial_success")
    state = SUCCESS      ← 跳过 POWER_ON/CONFIGURE 直接进入检测循环

else if running_before:  ← 曾经成功但现在不通
    powerOffModule()     ← 彻底重启 modem
    state = POWER_ON
```

第一次开机：`/tmp/modem_started` 不存在 → 创建 → `running_before=false`，从 `POWER_ON` 开始。重启后文件已存在 → 若已连接直接进 `SUCCESS`，否则重新上下电确保干净状态。

### 32.4 运营商扫描与切换

#### `parse_oper_list_info(deque_oper, oper_list_str)`

解析 `AT+COPS=?` 响应（格式：`(stat,"long_name","short_name","numeric",act),(...)...`）：

```
1. strstr(+COPS:) → 找到数据起始
2. 循环 strchr('(') + strchr(')') → 提取每个括号内的运营商信息
3. parse_oper_info_str() → 解析为 stat, long_oper, short_oper, numeric_oper, act
4. operator_map[long_oper] = numeric_oper    ← 更新名称→PLMN 映射
5. stat==1（可用）→ numeric_oper 入队到 deque_oper
```

#### `find_operator_code(operator_name)`

从 `operator_map` 中查找 PLMN，使用大小写不敏感的 `find()` 子串匹配（而非精确匹配），避免因运营商名称大小写差异导致查找失败。

---

### 32.5 运营商信息周期更新

在 `CHECK_CONNECTION` 成功后，每 10 次成功连接查一次 `AT+COPS?`（`oper_cnt++ % 10 == 1`）：

```cpp
response = sendATCommand("AT+COPS?\r\n", "/dev/ttyUSB5", 30);
if isCopsResponseNormal(response):
    operatorName = extractStringBetweenQuotes(response)
    plmn = find_operator_code(operatorName)
```

注意：查询用 `/dev/ttyUSB5`（命令通道），而 `AT+QNETDEVCTL`/`CFUN` 等控制命令用 `/dev/ttyUSB0`（数据通道），两个串口分工不同。

### 32.6 `main()` 函数结构

```
1. create_cpactive()    ← watchdog 注册，超时 30s
2. NanoReqHandler("tcp://127.0.0.1:38001")  ← IPC 请求处理线程
3. NetWork_EventPublisher::getInstance().init("tcp://127.0.0.1:48001")
4. ConfigParser("/etc/config/config.json") → TrafficMonitor::PacketLimit (key="C020102")
5. TrafficMonitor monitor("")
6. Imx6uDialer dial + signal(SIGINT/SIGTERM, signal_handler)
7. std::thread dialThread([&]{ dial.dial_loop(cpactive, netif_name, callback) })
8. cv.wait_for(TIMEOUT=360s, isInterfaceSet)  ← 等待拨号成功（网卡就绪）
9. monitor.check_CCINet_FlowOverLimit()       ← 流量超限监控（阻塞直到触发或退出）
10. dialThread.join() + led.turnOff() + exit(0)
```

`setInterfaceName()`：在 `dial_loop` 的 `callback` 中调用，`std::condition_variable cv.notify_one()` 唤醒 `main` 的等待。互斥锁 `mtx` 保护 `isInterfaceSet`，注意在 `wait_for` 后必须 `lock.unlock()` 才能让 `setInterfaceName` 正常加锁。

```
构造函数:

    openTrafficDatabase():
        sqlite3_open("/usrdata/traffic_record.db", &dbRef)
```

```sql

    ID INTEGER PRIMARY KEY AUTOINCREMENT,
    TotalValue REAL,
    SentValue REAL,
    ReceivedValue REAL,
    TrafficThreshold REAL,
    RecordTime TEXT NOT NULL
);
```

两张表结构完全相同：`MonthlyTraffic` 存当月数据，`HistoryTraffic` 存历史记录，均预填 60 条零值作为循环覆盖的缓冲槽。

#### 主要公开方法

| 方法 | SQL 操作 |
|------|---------|
| `insert(table, total, sent, received, threshold, time)` | `INSERT INTO ...` |
| `update(table, id, ...)` | `UPDATE ... WHERE ID = id` |
| `updateOldestRecord(table, ...)` | `SELECT ID ... ORDER BY RecordTime ASC LIMIT 1` → 更新最旧记录 |
| `remove(table, id)` | `DELETE FROM ... WHERE ID = id` |
| `query(table)` | `SELECT *`（调试用，输出到 stdout） |
| `getLastRecordFromDB(dbRef, table)` | `SELECT ... ORDER BY RecordTime DESC LIMIT 1` → `TrafficData` |
| `isLatestRecordMonthSameAsSystem()` | `strftime('%Y-%m', RecordTime)` == 系统当前年月 |
| `isCurrentOrLatestRecordTime1970(table)` | 检查系统时间或最新记录是否为 1970 年（时间未同步保护） |

#### 1970 年时间保护

`isCurrentOrLatestRecordTime1970()` 是一个重要的时间校验：嵌入式设备上电后如果 RTC 未同步，系统时间可能停留在 1970-01-01，此时流量统计数据的时间戳无效。调用方在执行月度清零或历史归档前应先检查该条件，避免将 1970 年数据误判为当月数据。

```c
    return strcmp((const char*) str1, (const char*) str2);
}
```

这是 Collections-C 库提供的通用字符串比较器，供排序、搜索等需要函数指针比较器的场景使用。在本项目中，`cc_deque` 操作（如查找特定运营商）可传入此函数指针进行字符串比较。
