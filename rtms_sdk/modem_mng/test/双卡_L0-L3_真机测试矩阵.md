# AG35 双卡 × 恢复档(L0–L3) 真机测试矩阵

> 目的：覆盖双卡切换（cold-select/fast-boot/方案A/C6/A/B 路径）与分级恢复（L0/L1/L2/L3）的真机验证。
> 适用版本：AG35 modem_mng **1.32.16**（及调试版 `1.32.x-rtest`）。设备：OpenWrt，二进制在 `/media/sdcard/modem_mng`。
> **1.32.16 起**：A4 回探——新键 `probe_back_interval_sec`(0=关缺省)。两种触发：兜底驻留(被迫切换后)按对称评分回探；驻留最优但漫游(REG=5)回探且**迁移须对面 home 注册**。回探与 OPER 的 COPS=0 恢复错开 ≥60s。测试项见 T0.10/T0.11/T0.12。日志格式：`probe-back(fallback)`/`probe-back(roam-home)`。
> **1.32.14 起判据变化**：REG=3 触发的切卡日志 reason 从 `A-no-net` 细分为 **`A-denied`**（切卡行为/时机不变，仅标签）——涉及 REG=3 场景的 grep（T2.5/T3.1）已更新为 `trigger(A-`；REG=0/弱信号仍打 `A-no-net`（T1.1/T1.2 不变）。历史实测记录里的 `A-no-net` 是 ≤1.32.13 旧版输出、保留不改。
> **1.32.15 起**：dualsim.json 缺键自动合并补写——老文件首启应见 `[SLOT] config: N missing key(s) merged into dualsim.json` 且原键值/_comment 不变、新键（如 switch_after_denied_sec）出现；第二次启动无 merged 日志（稳态零写入）。
> 约定：✅已测 / ⬜未测 / ⚠️需工具。每项给"触发指令/动作 + 预期日志(grep) + 通过判据"。
> **日志槽号命名（1.32.12 起）**：`[SLOT]`/心跳日志把 `phy1/phy2` 改为人读名 **`eSIM`(=phy1) / `Phy`(=phy2)**（如 `SLOT:eSIM`、`cur ICCID:xxx (Phy)`、`best=Phy -> drive Phy`、`HIT Phy`）。下方**判据/grep 已按 1.32.12 更新**；**历史实测记录（Tier 0/2/3 记录块）中的 `phyN` 是 ≤1.32.11 旧版输出、保留不改**（phy1=eSIM、phy2=Phy）。`/tmp/sim_slot`、`sim_slot_status.json` 仍是数字（机器读）。
> 证据级别：本矩阵所有"预期日志"均取自源码实际 `dial_log` 字符串（非臆测）。

## 0. 通用指令（先看这节）

### 0.1 运行 + 抓日志（重要：当前 SD 日志未落盘，主日志只进 console）
> 真机 logger 误判 SD「未挂载」→ 主日志只到 console。测试期**务必重定向到文件**再 grep，否则后台跑会丢日志。

**前置（必做）：确认只有一个 modem_mng 实例。** 本设备开机由 sw_mng/init 自启一个 modem_mng；若它还在跑，你手动再起一个就是第二实例，两个会抢 modem 数据呼叫/串口 AT，结果不可信。
```sh
ps w | grep "[m]odem_mng"      # 看几个实例、各自路径/参数
pidof modem_mng                # 列 PID
ls /etc/init.d/ 2>/dev/null | grep -i modem ; ls /etc/rc.d/ 2>/dev/null | grep -i modem   # 是否开机自启
# 若有系统自启实例：先停它（/etc/init.d/<svc> stop 或令 sw_mng 不拉起），只留待测的那个。
```
```sh
cd /media/sdcard
# 前台带重定向（推荐测试用）：
./modem_mng 2>&1 | tee /tmp/run.log
# 或后台：
./modem_mng > /tmp/run.log 2>&1 &
# 实时跟：
tail -f /tmp/run.log
# 版本确认（生产应 1.32.8；调试压测版应带 -rtest）：
```

### 0.3 构建指令（主机侧；调试压测版见 §3）
> 2026-06-30 实测修正：原指令缺三样、本机直接编不过——已补全并跑通（build exit=0，产物 466648B）。
> ① **必须传 `-DCMAKE_TOOLCHAIN_FILE`**：缺它 CMake 不进 `if(CMAKE_CROSSCOMPILING)` 分支、`dialer_lib` 不创建 →
>    报 `target "dialer_lib" which is not built by this project`（modem_mng/CMakeLists.txt:187）。
> ② **必须传 `-DWITH_RTMS_CORE=1`**：modem_mng 的 `add_subdirectory` 被它门控（apps/CMakeLists.txt:16-23，默认 OFF）→
>    缺它根本没有 `modem_mng` 目标（`No rule to make target 'modem_mng'`）。
> ③ **必须清 RK3576 环境污染**：本机 `which cmake` 解析到 RK3576 buildroot 的 cmake、且 `CC/CXX/CROSS_COMPILE/SYSROOT`
>    都指向 aarch64-buildroot；AG35 toolchain 文件未硬设 `CMAKE_C_COMPILER`（依赖 env `CC/CXX`）→ 不覆盖就用了
>    RK3576 的 aarch64 gcc，编译器自检即 `cannot find Scrt1.o`。须显式 `export CC/CXX=AG35 gcc/g++` + `unset` RK3576 变量。
```sh
cd /home/tronlong/lyp/code/rtms_sdk
AG35BIN=/home/tronlong/lyp/SDK/AG35/ql-ag35-1806e-gcc-13.3.0-glibc-v1-toolchain/bin
export QL_MODULE_PLATFORM=AG35
export QL_SYSROOT_DIR=/home/tronlong/lyp/SDK/AG35/ql-ol-extsdk-quectel_ag35-xxt_r01a04_sdk/ql-sysroots
export STAGING_DIR=$QL_SYSROOT_DIR/staging_dir
export PATH=$AG35BIN:$PATH
export CC=$AG35BIN/arm-openwrt-linux-gcc CXX=$AG35BIN/arm-openwrt-linux-g++   # ③ 盖掉 RK3576 的 CC/CXX
unset CROSS_COMPILE SYSROOT RK3576_TOOLCHAIN                                  # ③ 清 RK3576 污染
# 生产构建：
cmake -S . -B build_ag35 \
  -DCMAKE_TOOLCHAIN_FILE=$PWD/cross-profiles/toolchain_armv7-a-ag35.cmake \   # ①
  -DWITH_RTMS_CORE=1 \                                                        # ②
  -DENABLE_FAST_RECOVERY_TEST=OFF
cmake --build build_ag35 --target modem_mng -j4
# 产物：build_ag35/apps/modem_mng/modem_mng  → scp 到设备 /media/sdcard/
```

### Tier 2/3 实测记录（2026-06-30 16:29，AG35 1.32.11-rtest，停 eSIM —— 运行期 A-no-net 闭环）
- **场景**：编辑 last-good=1 强制开机落 eSIM(phy1)，`switch_after_sec=60`，运行中**运营商侧停掉 eSIM**。
- **T2.5 + T1.1 + T3.1 一次三验 ✅**：
  ```

  16:29:07 Net Fail 31s → Trigger Level 2 (REG=0加速) → CFUN toggle → Start failed -1001  ← L2 先救同卡失败
  16:29:37 trigger(A-no-net): down 61s REG=3 CSQ=19 count=0/3 -> switch card   ← A路径触发(switch_after=60)
  16:29:37 switching to role=SECONDARY phy=2 → cur ICCID:898604(phy2) → data start OK
  16:29:50 Recovered via card-switch (now phy2). Down 74s. Ping OK
  16:29:50 residency=fallback ... last-good kept unchanged   ← 方案A
  ```
