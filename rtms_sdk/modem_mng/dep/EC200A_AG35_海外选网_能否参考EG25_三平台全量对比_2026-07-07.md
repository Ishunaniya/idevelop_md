## 1. 背景

`modem_mng` 通过编译期宏（由 `QL_MODULE_PLATFORM` 选择）支持三套拨号实现，三者各自都带有"手动选运营商（`AT+COPS=1,2`）"能力，但**起源不同、架构不同**：

| 平台 | 宏 | 入口 | 选网代码位置 |
|---|---|---|---|
| EC200A / **AG35** | `USE_EC200A_DIAL` | `dialer_ec200a.cpp` | `ec200a/oper/oper.{cpp,h}`（独立 worker）+ `ec200a/dial/dial.cpp`（触发/消费/恢复/配置） |
| EG25G | `USE_EG25_DIAL` | `dialer_eg25.c` | `eg25/dial/dial.c`（内联进主 FSM）+ `eg25/apn/apn.c`（配置） |
| MCIMX6Y2CVM08AB | `USE_IMX6U_DIAL` | `dialer_imx6ull.cpp` | `dialer_imx6ull.cpp`（内联 FSM，全文件内） |

> AG35 复用 EC200A 源码路径，选网功能通过 `#ifdef QL_MODULE_PLATFORM_AG35` 与 dualsim.json 开关启用；EC200A 本身该开关默认关、维持定义默认 0。

## 2. 三份实现的起源（已核验）

| 实现 | 上游来源 | 核验依据 |
|---|---|---|
| **EG25** 的 `list_oper`/`select_oper` | **上游 `open_dial_for_artery` 自带** | `open_dial_for_artery/src/dial/dial.h:64-65` 有 `dial_stat_list_oper`/`dial_stat_select_oper`；`src/apn/apn.c` 有 `is_oper_select`；README §196 明写。✅ 直接读上游源码 |
| **AG35/EC200A** 的 `ec200a/oper/` | **本仓库原创**，上游 `open_dial` 无此功能 | 全仓扫 `open_dial` 仅 `nw/nw.c` 一个 `item_ql_nw_network_scan` **诊断测试菜单项**，无 `is_oper_select` / `COPS=1` / `list_oper` 任何一项。✅ |
| **IMX6** 的 `LIST_OPERATOR`/`SELECT_OPERATOR` | 本仓库内（`dialer_imx6ull.cpp`） | 见下 §5 |

**顺带核出的强事实**：`open_dial_for_artery/src/apn/apn.c:217` 把 `is_oper_select` **默认置 true**，仅国内移动卡显式设 false，apn.json 里挪威/泰国/印尼等海外卡都不带该键 → 默认 true → **上游 EG25 本就是"海外卡默认走手动选网"设计**。

## 3. EG25 选网实现详解（已读全）

### 3.1 触发
- 配置字段 `is_oper_select`（**per-APN / per-SIM**，`apn.json`，默认 **true**，`apn.c:500-508`）。
- 拨号反复超时时（`dial.c:1380-1393`）：
  - `is_oper_select == true` → 进 `dial_stat_list_oper`（逐家试）；
  - `is_oper_select == false` → 先发 `AT+COPS=0` 掰回自动（对齐上游 `open_dial_for_artery bcd3b90`），再进 `reg_check`。

### 3.2 扫网 + 选网（内联 FSM，`dial.c:1440-1579`）
- `dial_stat_list_oper`（L1440）：`AT+COPS=?`（**`dial.c:1446`**，180s）→ `parse_oper_list_info` 灌 `cc_deque`；候选表落 SD 卡日志 `[OPER] Candidate list`。
- `dial_stat_select_oper`（L1500）：取队首 `AT+COPS=1,2,<plmn>`（60s，收到 OK 即早退）；失败累计 `AT_RETRY_NB` 次后出队换家；成功后走 `stop_cfun → start_cfun`。

### 3.2.1 解析实现体（`eg25/nw/nw.c:491-535`，已读全）
- `parse_oper_info_str`（L491）：对单项 `2,"CHN-UNICOM","UNICOM","46001",2` **按逗号切 5 字段**（stat / 长名 / 短名 / 数字码 / AcT），每字段长度**夹到 `OPER_NAME_LENGTH-1` 防溢出**（L505-510）。
- `parse_oper_list_info`（L537）：`strstr("+COPS:")` 后逐 `(...)` 项解析入 deque。
- 该副本为 **EG25 专属**；**IMX6 在 `dialer_imx6ull.cpp` 另有一份独立副本**（还多一层 `operator_map` 名称→码映射，见 §5）；**AG35 无任何文本解析**（`ql_nw_network_scan` 直接给 `ql_nw_scan_entry_info_t` 结构体，`mcc`/`mnc` 直取，`oper.cpp:134`）。三家解析路径互不复用。

### 3.3 回自动 / 注册超时自愈（`reg_timeout_handler`，`dial.c:1793-1909`，已读全）
本质是 **SIM 禁卡 / 注册超时的策略分派**（Roamlink 策略机器）：
- **策略1/2** + roamlink 可用 + 非 license_pending → 切 Roamlink 通道（`apn_obj_free` + `roamlink_start_*`）。
- **策略4（FORCE_SIM）**：查 `AT+COPS?`，若 `≠ +COPS: 0` → 发 `AT+COPS=0` 手动锁自愈（L1820-1847）；若已连过则**让位 L2** 避免双 CFUN。
- **冷启动 / roamlink 不可用 / license_pending**：CFUN 复位重试，复位前落 `[REG DIAG]` 根因快照（CEREG/COPS/CEER/QENG）。

> 关键：EG25 的"回自动 COPS=0"由 **reg-timeout（300s 未注册）**触发，且深度绑定 Roamlink 四策略——**与 AG35 无 Roamlink（是 DSSS 双卡）的架构基本不相关**。

### 3.4 线程 / SDK
`Ql_SendAT(fd, cmd, expect, timeout_ms, rsp)` —— **有超时参数**（`dial.c:1446` 传 `180000`；`dial.c:1519` 注释"收到 OK 即早退，不死等满超时"）。因此选网可**内联在 `dial_stat_*` 主 FSM**，阻塞调用最坏等满 timeout 就退。

## 4. AG35 选网实现详解（已读全）

### 4.1 触发（`dial.cpp`，`oper_start_select_round` 全仓唯一调用点 L1695）
门控条件（L1685-1695）：
```
enable_policy_recovery==1 && !has_connected_once && g_oper_select_enable
  && oper_is_available() && !slot_switching_active && state==OPER_ST_IDLE
  && never-connected 时长 > 阈值（轮间节流 10min）
```
即 **never-connected 旁路是唯一触发**：本次开机从未连上网 && 开关开 && 断网超阈值。已连过的设备走 L1/L2/L3 恢复阶梯；`has_connected_once` 不落盘，L3 `exit(1)` 重启后归零 → 重新进 never-connected 旁路接力。

### 4.2 扫网 + 选网（`oper.cpp` detached worker）
- 扫网用 **`ql_nw_network_scan` 结构化 API + 异步回调**（`oper.cpp:102`），不解析文本；结果直接读 `ql_nw_scan_result_list_info_t` 结构体，过滤 FORBIDDEN/CURRENT_SERVING + 去重，灌 `std::deque`。
- 逐家 `AT+COPS=1,2,"<plmn>"`（`oper.cpp:161`），单轮最多 5 家；成功后 `CFUN 0/1` 刷新注册态再重建数据呼叫；全败则发 `AT+COPS=0` 清手动模式残留。
- 队列跨轮保留（失败出队不复试，耗尽才重扫），超 30min 时效整队作废重扫（车载移动后旧位置候选无意义）。

### 4.3 消费侧（`dial.cpp:1219-1242`）
`dial_loop` 每轮 `oper_get_state()`：读到 `DONE_SELECTED/DONE_EXHAUSTED` 打印并 `oper_consume_result()` 复位 IDLE；`DONE_SELECTED` 时重新武装 COPS=0 恢复；`RUNNING>35min` 打一次性卡死自证日志（`ql_atc_send` 无超时，卡死则功能静默失效，此日志是现场唯一可见性）。

### 4.4 回自动（`dial.cpp:1414-1425` + `oper.cpp` restore_worker）
连网稳定 **10min → 发 `AT+COPS=0`** 恢复自动（独立 `oper_restore_worker`，先 `AT+COPS?` 查模式，仅 mode==1 才发，幂等）；同时清理上次进程被 L3 杀掉后 NV 残留的手动模式。**触发时机是"稳定 10min"，不是 EG25 的"reg-timeout"。**

### 4.5 线程 / SDK（**架构分叉的根因**）
`ql_atc_send(char *req, char *rsp, int rsp_len)` —— **无超时参数**（`ql_atc.h:80` 原型确认，仅 `ql_atc_send_async` 带回调）。一旦卡死即永久阻塞，若内联则 atc 服务卡死 = `dial_loop` 连同 L1/L2/L3 恢复阶梯一起冻死（且 sw_mng 看门狗不杀活进程）。**故 AG35 被迫用一次性 detached worker 隔离**，并需一套独立 `oper_state_e`（IDLE/RUNNING/DONE_SELECTED/DONE_EXHAUSTED）让主循环异步消费。

### 4.6 配置（`dial.cpp:741-885` + `config/dualsim.json`）
`oper_select` 在 `/usr/dial/dualsim.json`（**设备级全局**，modem_mng 自持/合并升级，**不走 config.json**），**白名单 `==1` 才开，缺省 0 = 关（fail-closed）**。旧 config.json 键 `C020601` 已弃用（不在 rtms_client schema、会被整文件重生成抹除，`dial.hpp:20/72/109`）。

## 5. IMX6 选网实现详解（已读全 `dialer_imx6ull.cpp` L557-793）

### 5.1 触发（最粗暴）
`CHECK_CONNECTION` 连续 ping 失败 5 次（`checkConnectionAttempts` 达 5）→ `state = LIST_OPERATOR`（L622-638）。**无任何开关、无 never-connected 门控——无条件触发。**

### 5.2 LIST_OPERATOR（L687）
- 优先用**历史 PLMN**（`plmn` / `stored_plmn`）：`AT+COPS=1,2,"<plmn>",7`，每步 `QNETDEVCTL=0` + `CFUN 0/1` 包裹 → `WRITE_TO_MODEM`。
- 否则 `AT+COPS=?`（180s）文本解析进 `deque_oper`（`parse_oper_list_info` + `CC_Deque` + `operator_map` 名称→码映射）。

### 5.3 SELECT_OPERATOR（L741）
弹队首 `AT+COPS=1,2,<plmn>,7`（CFUN 0/1 包裹）→ `AT+COPS?` 用 `isCopsResponseNormal` 验证 → `WRITE_TO_MODEM` 或退回 `LIST_OPERATOR`。

### 5.4 特点
- **独有"历史 PLMN 持久优先"**（`write_plmn_to_file` / `stored_plmn`）——EG25/AG35 都没有。
- **从不发 `AT+COPS=0` 回自动**。
- 用 `sendATCommand` 走 `/dev/ttyUSB0`，**有 per-命令超时**（30/60/180s）→ 与 EG25 一样可内联 FSM。

## 5.5 AG35 特有约束：选网 × 双卡单待（DSSS）耦合 —— EG25 无此维度（已读全）

这是"能否参考 EG25"里被忽略、但决定性的一维：**AG35 上 `[OPER]` 选网与 `slot_mgr`（DSSS 双卡单待）共存于同一条 `dial_loop` / 同一条 AT 通道，两者有显式互斥与分层；而 EG25 根本没有 DSSS**（EG25 的"双卡"是 Roamlink 虚拟卡，机制完全不同且也仅 EG25 有）。因此 EG25 的选网模型天然缺少这一层约束，**照搬过来会直接违反 AG35 的 per-USIM 单线程并发约束**。

### 5.5.1 时间互斥（三方永不并发抢 AT 通道）
- **oper 触发**（`dial.cpp:1685-1695`）门控含 `!slot_switching_active && oper_get_state()==OPER_ST_IDLE`——切卡进行中不启动选网。
- **A4 回探**（`dial.cpp:1441-1445`）门控含 `(!g_oper_select_enable || oper_get_state()==OPER_ST_IDLE)`——选网轮进行中不回探。
- **restore worker**（`oper.cpp:379`）`oper_get_state()!=IDLE` 时不抢 AT 通道。
- 底层约束：`slot_mgr` 是**单线程、仅 dial_loop 调用**（per-USIM 并发约束，CLAUDE.md 记载）；oper worker 虽独立线程，但靠上述状态门控与 slot 操作错开。

### 5.5.2 分层协作（切卡在前，选网兜底在后）
`slot_mgr.c:209-213`（C4）在**每次换卡后发 `AT+COPS=0` 清手动残留**，注释明写与 OPER 的分层：

> 换卡后新卡必须自动选网——上一运行 / 海外选网（[OPER]）可能把模组钉在 COPS=1 手动模式指向某运营商，新卡若被该残留锁住会注册失败、冷启动评分也被污染……**与 OPER 共存时，这条保证"先换卡→新卡自动注册→（若仍数据不通再由 OPER 在该卡上 COPS 选网）"的分层。**

即 AG35 的完整故障恢复次序是：**切物理卡（slot_mgr）→ 新卡 COPS=0 自动注册 → 仍数据不通才由 OPER 在该卡上逐家 COPS=1 选网**。这是"换硬件卡"与"在当前卡上换软件运营商"的两级，EG25 只有后者（且其"换卡"是 Roamlink 虚拟卡走完全不同的 `reg_timeout_handler` 策略分派）。

### 5.5.3 结论
**这一维 EG25 完全没有对应物**，反而是"EG25 模型更不可迁移"的又一硬证据：AG35 选网必须服从 DSSS 的槽互斥与分层，而 EG25 的内联 FSM 里没有任何槽概念。

## 7. 对原问题的定论

**AG35 与 EG25 真正的共享面只有一层：`COPS=1,2` 选网指令 + `CFUN 0/1` 包裹——而且这层 IMX6 也一样。** 除此之外，触发 / 扫网 / 历史 / 回自动 / 线程 / 配置**六维全部三方分叉**，且 AG35 每一维的分叉都由**自身硬约束**决定，不是"没参考"：

| AG35 的分叉 | 根因（为什么不能照搬 EG25） |
|---|---|
| 用 detached worker 而非内联 FSM | `ql_atc_send` **无超时**，内联会冻死整个 dial_loop + 恢复阶梯（EG25/IMX6 的 `Ql_SendAT`/`sendATCommand` 有超时，可内联） |
| 用结构化 scan API 而非文本解析 | open_dial 自带 `ql_nw_network_scan` 结构化 API，无必要退回文本解析 |
| 配置默认关（opt-in）而非 EG25 默认开 | **COPS=1 选网轮真机零验证**，故意 fail-closed；与 EG25 默认 true **语义反转** |
| 回自动用"稳定 10min"而非 reg-timeout 那套 | EG25 reg_timeout 深绑 Roamlink 四策略；AG35 无 Roamlink（是 DSSS 双卡），不适用；AG35 已有等价物 |

**结论：能从 EG25 借的（COPS/CFUN 编排）已经借了（`oper.cpp` 注释多处"对齐 EG25"可查），剩下 EG25 独有的机制要么与 AG35 架构冲突、要么 AG35 已有等价物、要么是有意反转。参考价值有限且已基本用尽。**

`oper.cpp` 中已显式"对齐 EG25"的点（本轮读到）：
- L28：`AT+COPS=?` 同级超时 180s —— 对齐 EG25（注释写 `dial.c:1412`，**实测该 `AT+COPS=?` 调用在 `dial.c:1446`**；注释行号偏旧，功能对齐无误）
- L192：先断数据呼叫再扫网 —— 对齐 EG25（注释写 `dial.c:1345`；EG25 的 `dail_stop_data_call` 在选网前的实际调用见 `dial.c:1378`）与 IMX6 `LIST_OPERATOR`
- L230：选网成功后 `CFUN 0/1` 包裹再重建呼叫 —— 对齐 EG25 `stop_cfun → start_cfun`
- L217 / oper.h：队列"失败出队不复试、耗尽才重扫" —— 对齐 EG25 队列语义

## 8. 可借鉴清单（全量才看得出）

| 来源 | 机制 | 对 AG35 的价值 | 建议 |
|---|---|---|---|
| **IMX6**（非 EG25） | **历史 PLMN 持久优先**（`stored_plmn` / `write_plmn_to_file`） | 三家里**唯一 AG35 缺、真正值得补**的一项：优先复用上次成功运营商，加快选网收敛、减少全量扫网断流 | ✅ 值得评估移植（注意：AG35 是双卡，历史 PLMN 需按物理槽/ICCID 区分，避免跨卡误用） |
| EG25 | `parse_oper_list_info` 文本容错、候选表落 SD 卡日志 | AG35 用结构化 API 已有等价可观测性 | 已覆盖，无需借 |
| EG25 | reg-timeout COPS=0 手动锁自愈 | AG35 已有 restore_worker + 全败兜底 COPS=0 | 已覆盖，触发时机不同但语义等价 |
| EG25 | `is_oper_select` 默认 true（海外卡默认选网） | 与 AG35 fail-closed 有意反转（COPS=1 未验） | ❌ 不该借，会破坏 fail-closed 安全边界 |

> 若要优化 AG35 选网收敛速度，该抄的是 **IMX6 的 `stored_plmn` 持久**，而非 EG25。

## 11. IMX6 完整拨号状态机全流程（非选网部分补全，已读全）

前文 §5 只讲了 IMX6 的选网分支；这里补全整机 FSM，便于判断"历史 PLMN"机制嵌在何处。状态枚举（`dialer_imx6ull.cpp`）：`POWER_ON / CONFIGURE_USB / WRITE_TO_MODEM / CONFIGURE_NETWORK / CHECK_CONNECTION / SUCCESS / LIST_OPERATOR / SELECT_OPERATOR / FAILURE_RETRY`，初始态 `POWER_ON`（L313）。

### 11.1 初始化（L396）
`stored_plmn = read_plmn_from_file("/usrdata/plmn")` —— 开机先读上次持久的历史 PLMN。

### 11.2 状态流转

| 状态 | 行 | 动作 | 转移 |
|---|---|---|---|
| `POWER_ON` | L457 | `powerOnModule()`；`brctl delif bridge0 usb0` | → CONFIGURE_USB |
| `CONFIGURE_USB` | L463 | `configureUSBModule()` | ==0 → WRITE_TO_MODEM；否则轮询 `/dev/ttyUSB0`，超 `maxAttempts` → POWER_ON |
| `WRITE_TO_MODEM` | L507 | `ATE0` / `AT+QCFG="usbnet",1` / `AT+QNETDEVCTL=3,1,1` | → CONFIGURE_NETWORK。**注：这里"开机用 stored_plmn 发 COPS=1,2"的代码被注释掉（L513-521）** |
| `CONFIGURE_NETWORK` | L528 | `killall -9 udhcpc`；等 `usb0` 出现（5×2s）；`udhcpc -i usb0` | 未出现 → FAILURE_RETRY；否则 → CHECK_CONNECTION |
| `CHECK_CONNECTION` | L557 | ping google | 成功 → `touch /tmp/dial_success`，每 10 次刷新一次 plmn（空则回落 `stored_plmn`，L614-618），→ SUCCESS；<5 次失败 → 留原态 + 告警；第 5 次失败 → **LIST_OPERATOR** |
| `SUCCESS` | L643 | 设网卡 `usb0`、`callback()`、`sleep(10)` | → CHECK_CONNECTION。**其中会解析 COPS 的 `#if 0` 块整段禁用（注释"会导致断网"，L644-674）** |
| `LIST_OPERATOR` | L687 | **历史优先**：`plmn` 非空 → `COPS=1,2,"<plmn>",7`（CFUN0/1 包裹）→ WRITE_TO_MODEM；否则 `COPS=?` 解析入 deque | 有候选 → SELECT_OPERATOR；无 → POWER_ON |
| `SELECT_OPERATOR` | L741 | 弹队首 `COPS=1,2,X,7`（CFUN0/1 包裹）+ `COPS?` 验证 | 正常 → WRITE_TO_MODEM；异常 → LIST_OPERATOR |
| `FAILURE_RETRY` | L786 | `rm /tmp/dial_success`；`sleep(2)` | → POWER_ON |

### 11.3 历史 PLMN 持久化实现（`dialer_imx6ull.cpp:1036-1082`，已读全）
- `read_plmn_from_file`（L1036）：`cJSON_Parse` 读 `{"plmn":"..."}`，取 `plmn` 字段。
- `write_plmn_to_file`（L1063）：`mkdir /usrdata`；`cJSON` 写 `{"plmn":"..."}`；**普通 `ofstream` 覆盖写，非原子；无 TTL；无 per-SIM/per-slot 键**。写入点在拨号成功分支（持久当前可用 PLMN）。

### 11.4 对 AG35 的可迁移性评估
- **可借鉴的核心思想**：`LIST_OPERATOR` 历史优先（`if(!plmn.empty())`）——命中时**跳过整段 `AT+COPS=?` 扫网**，直接对上次成功运营商发 `COPS=1,2`，大幅缩短选网收敛。
- **IMX6 实现的不足（AG35 移植必须改掉）**：① 单一全局 `/usrdata/plmn`，**无卡区分**——AG35 是 DSSS 双卡，直接照搬会把 A 卡的运营商用到 B 卡；② 非原子写，可能被 nanomsg 并发读到半截；③ 无 TTL，车载移动后旧位置 PLMN 会长期误用（AG35 选网队列已有 30min 时效正是为此）。

## 12. 实施草案：移植"历史 PLMN 优先"到 AG35（**未实施 / 设计稿**）

> ⚠️ **前置门槛**：本草案是选网**收敛速度优化**，其价值建立在"COPS=1 选网轮本身能工作"之上。而 §8/CLAUDE.md 明确 **COPS=1 选网轮至今零真机验证、生产必须 `oper_select=0`**。因此本草案**应在 §8 真机验证通过后再实施**，否则是在未验证的地基上加功能。下文为设计留档。

### 12.1 目标
在 AG35 选网轮开始时，若存在**本卡**上次成功的历史 PLMN 且未过期，**先试它一家**（`COPS=1,2,<history>`）；成功则跳过 `ql_nw_network_scan`（省 ~180s 扫网 + 多家试错），失败则回落现有全量扫网流程。

### 12.2 关键设计决策（对齐 AG35 既有范式，不照抄 IMX6 缺陷）

| 维度 | 决策 | 依据 |
|---|---|---|
| 持久粒度 | **按 ICCID 键**存 `{iccid, plmn, ts}`，用前校验当前卡 ICCID 匹配才采用 | 修 IMX6 缺陷①：DSSS 双卡不能跨卡误用 |
| 文件 | `/media/sdcard/sim_oper_last_good`，**原子 tmp+rename 写** | 对齐 `slot_mgr` 的 `SM_LAST_GOOD_PATH` 同盘 + `sim_slot_status.json` 原子写范式；修 IMX6 缺陷② |
| TTL | 新增 `oper_last_good_ttl_sec`（dualsim.json，**默认 0=关**，建议启用值 ≤ 数小时） | 对齐 `slot_mgr` 的 `last_good_ttl_sec`（默认 86400）+ 选网队列 30min 时效；修 IMX6 缺陷③；fail-closed |
| 写入时机 | 仅在 **ping 成功且驻留最优**（非兜底）时写，记当前 serving PLMN + 当前 ICCID | 对齐 `slot_mgr_mark_good` "只在 optimal residency 写、forced 不写"纪律 |
| 读取/使用时机 | `oper_worker` 内，队列空、扫网**之前**：ICCID 匹配 + 未过期 → 先 `oper_try_cops(history)` | 命中即 `selected`，跳过 `oper_do_scan()` |
| 失败回落 | 历史 PLMN 试败（可能已变 FORBIDDEN）→ 照常 `oper_do_scan()` 全量扫 | 代价仅 1 次 COPS 尝试，有界 |
| 与门控关系 | **不改任何触发**（仍 never-connected 旁路唯一触发）；不改 DSSS 互斥（§5.5） | 纯扫网内部的 scan-skip 优化 |

### 12.4 风险与守卫
- **serving PLMN 获取**：需一条可靠取当前驻留 PLMN 的路径（`AT+COPS?` 解析或 SDK `ql_nw`）；注意 §漫游时 COPS 给的是漫游网 PLMN，历史命中后仍是漫游网——可接受（本就是"上次能上网的那家"）。
- **车载移动**：TTL 是唯一防线；建议启用值明显小于 `slot_mgr` 的 24h（选网队列 30min 时效可作参考量级）。
- **FORBIDDEN 漂移**：历史 PLMN 现已被禁 → 白白试 1 次 COPS，有界，回落扫网时 `oper_do_scan` 会过滤掉 FORBIDDEN。
- **fail-closed**：`oper_last_good_ttl_sec` 默认 0=关，且整功能仍受 `oper_select==1` 白名单总闸约束。
