## 1. 项目目标与范围

项目名称为“基于中控架构的智能安全 v1.0”中的部分功能开发。目标是在起重机现有摄像头和中控硬件上实现五项视觉安全检测功能，并使三一具备后续维护、参数调整和模型迭代能力。功能由外包合作开发，需交付数据、模型、完整工程源码、配置、测试及运维资料。

| 编号 | 本项目范围内的功能 | 通俗含义 |
| --- | --- | --- |
| F-01 | 载荷附近人员检测 | 监测吊钩地面投影周围危险区域的人员。 |
| F-02 | 载荷下方人员检测 | 监测吊载下方及相关遮挡区域的人员。 |
| F-03 | 大臂下方人员检测 | 监测大臂轴线下方扇形区域的人员。 |
| F-04 | 高度限位开关安装状态识别 | 判断限位开关重锤及钢丝绳是否正确安装。 |
| F-05 | 卷扬冰雪检测 | 判断主、副卷扬卷筒上的冰雪覆盖是否超限。 |

**系统边界：**本系统是安全感知与告警辅助系统，输出检测结果、目标位置、置信度、告警事件和日志；不直接控制起重机底层动作。最终控制执行策略由三一主控系统决定。（原文 §1.4）

## 2. 使用场景和术语

| 术语 | 本文含义 |
| --- | --- |
| 作业状态 | 起重机发生回转、变幅、起落钩或伸缩臂等动作。 |
| 静止状态 | 未发生上述作业动作；前三项人员检测仍需返回结果，但原文规定不报警。 |
| 吊钩投影 | 吊钩在地面的投影点，用作 F-01、F-02 区域中心。投影计算方法待设计。 |
| 幅度 | 大臂根部至臂头地面投影位置的水平距离；与吊钩周围的 10 米警戒半径不同。 |
| 精确率／召回率／准确率 | 不同的统计指标；原文名称未统一，见第 11 章待确认项。 |
| 告警与提示 | “告警”表示触发安全预警；原文另写静止时“提示”但不报警，提示形式待确认。 |

## 3. 运行输入、输出与通用流程

### 3.1 已给定的硬件和软件环境

| 设备或环境 | 原文规定 |
| --- | --- |
| 臂头摄像头 | 1 个，1920×1080，25 fps，水平视场角 6.74°～60°，变焦 IPC。 |
| 驾驶室顶长焦摄像头 | 2 个，1920×1080，25 fps，水平视场角 61°，AHD。 |
| 卷扬摄像头 | 2 个，1920×1080，25 fps，水平视场角 140°，AHD。 |
| 处理器与系统 | 适配 RK3588 Linux、高通 8775 Android；文档另列 Ubuntu 20.04 无桌面版 Linux，处理器环境内存 ≤8 GB。 |
| 开发与运行依赖 | C++17、GCC、CMake、OpenCV 4.5.4、RKNN SDK 2.1 及高通 QNN 适配；配置采用 YAML。 |

**通用处理链：**采集图像和工况 → 可选图像预处理 → 量化模型推理 → 业务规则判定 → 输出检测及告警信息。模型训练阶段输出标准 ONNX，目标平台使用 INT8 量化模型和硬件加速；不采用纯 CPU 推理。（原文 §2.1）

| ID | 通用要求 | 原文依据 |
| --- | --- | --- |
| GEN-01 | 所有功能必须使用项目现有硬件，不额外增加硬件。 | §1.5 |

| GEN-05 | 相机遮挡、模型加载失败、信号超时应输出异常；光学致盲场景应提示摄像头故障。 | §4、§6.3 |

## 4. 功能需求

### 4.1 F-01 载荷附近人员检测

| ID | 需求 | 原文依据 |
| --- | --- | --- |
| F01-01 | 功能开启后持续监测以吊钩地面投影为中心、半径 **10 米**范围内的人员。 | §3.1.1～3.1.2 |
| F01-02 | 作业状态下，在范围内连续 **3 帧**检出人员时报警。 | §3.1.2 |

| F01-04 | 未输入回转、变幅、起落钩和伸缩臂工况数据时，在检测范围内检出人员应**立即报警**。 | §3.1.2 |
| F01-05 | 应识别全身、半身、穿戴安全帽或反光衣、局部遮挡及多人场景的人员，并过滤设备、物料和阴影等干扰。 | §3.1.3 |
| F01-06 | 应输出人员相对吊钩投影中心的距离与顺时针夹角。 | §3.1.4 |
| F01-07 | 详细章节要求准确率 ≥92%、召回率 ≥92%、识别响应时间 ≤200 ms；第 6.1 节另写精确率 ≥92%，统计口径待统一。 | §3.1.4、§6.1 |

### 4.4 F-04 高度限位开关安装状态识别

| ID | 需求 | 原文依据 |
| --- | --- | --- |
| F04-01 | 在备车阶段通过臂头摄像头识别三种状态：重锤未安装、重锤已装但起升钢丝绳未穿过中心孔、正确安装。 | §3.4.1、§3.4.3 |
| F04-02 | 上车上电、功能开启并处于准备状态，且大臂为基本臂长、根部角度 **≥5°**时开启检测；另一段写“超过 5°”，5°边界待确认。 | §3.4.2、§3.4.4 |
| F04-03 | 累积检测帧数 **≥10**、中途静止 **≥15 秒**或根部角度 **＞75°**时结束检测并返回结果。 | §3.4.2 |
| F04-04 | 结果不是“正确安装”时，输出具体异常状态并报警。 | §3.4.4 |
| F04-05 | 详细章节要求准确率 ≥92%、召回率 ≥92%、结果响应 ≤15 秒、帧率 ≥1；第 6.1 节另写精确率 ≥92%。 | §3.4.4、§6.1 |

### 4.5 F-05 卷扬冰雪检测

| ID | 需求 | 原文依据 |
| --- | --- | --- |
| F05-01 | 通过卷扬摄像头监测主、副卷扬卷筒表面冰雪，计算覆盖面积占比，并区分冰雪与结构纹理、漆面色差；功能描述还提到钢丝绳积雪。 | §3.5.1、§3.5.3 |
| F05-02 | 上车上电并开启功能后开始检测；覆盖面积超过设定阈值时报警并退出检测。阈值和退出后的恢复规则待确认。 | §3.5.2 |
| F05-03 | 支持不同光照、雨雪和弱光场景；离线样本应包含正常和不同覆盖占比的异常样本。 | §3.5.4 |
| F05-04 | 详细章节要求准确率 ≥92%、召回率 ≥92%、检测响应时间 ≤1 秒；第 6.1 节另写精确率 ≥92%和检测延迟 ≤200 ms，计时范围待确认。 | §3.5.4、§6.1 |

## 5. 对外接口、配置和错误处理

| ID | 接口或规则 | 必要行为 | 原文依据 |
| --- | --- | --- | --- |
| INT-01 | `initialize(config)` | 加载模型、分配资源、可选预热；失败返回错误码、记录日志并回滚已分配资源；重复调用不能重复加载或泄漏。原文的“如 60 秒”是初始化超时示例，实际阈值待定。 | §5.3 |
| INT-02 | `detect(frame)` | 输入标准化图像和工况数据；返回检测目标、置信度和告警状态等。帧格式、时间戳、坐标系和线程约定待定义。 | §5.3 |
| INT-03 | `release()` | 释放推理算力、图像缓存、句柄、模型和临时资源。 | §5.3 |
| INT-04 | `updateConfig(config)` | 校验参数合法性，动态更新业务配置，更新时无需重启算法模块。 | §5.3 |
| INT-05 | YAML 配置 | 支持嵌套、数组、注释和多级参数。 | §1.5、§2.2、§5.4 |
| INT-06 | 模块内部结构 | 底层推理库采用 PIMPL；类的拷贝、移动构造和裸指针规则须按原文进一步明确。 | §5.1 |

错误码为 32 位无符号整数，格式 `0xMMMMEEEE`：高 16 位是模块号，低 16 位是错误号。低 16 位 `0x0000～0x0FFF`保留且仅 `SUCCESS=0`；`0x1000～0xBFFF`为评审管理的通用错误；`0xC000～0xFFFF`供各功能自定义。通用错误覆盖基础、模型、推理、配置、网络和存储；自定义错误须在详细设计中列明编码、名称、触发条件和建议处理措施。（原文 §5.2）

前三项人员实车测试还规定照度约 **800～100000 lx**、环境温度 **-20～+45℃**、风速 **≤8.9 m/s**；F-05 台架电压为 **24 V±1 V**。这些是**原文测试条件**，不能直接当成所有场景的功能适用边界。第 8 章的详细操作步骤仍以原始 Word 为准；本整理稿保留决定验收结论的条件、动作和判据。
