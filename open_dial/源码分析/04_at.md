# 04 — at/at.c + at/at.h

## 一、文件职责概述

AT 访问层。经外部命令 `serial_atcmd <cmd>`（popen）发送 AT 命令、解析首个/匹配行、格式化诊断行。**均为纯函数、不依赖运行期状态**（自 dial.c 剥离）。`exec_cmd_safe` 及三个 `unused` 的 getter 为内部 static，不导出。

> 所有 getter 都走 `popen("serial_atcmd at+xxx","r")`，而非 SDK `Ql_SendAT`——即 AT 层实际是**外部进程 serial_atcmd**，dial 只解析其 stdout。

## 二、逐函数分析

### `static int exec_cmd_safe(cmd, out_buf, buf_size)`（`at.c:20-36`）
- popen 读**一行** fgets 到调用方 buffer，去尾 `\n`；无输出置空串。popen 失败 -1，否则 0。

### `int get_csq_value_safe(void)`（`at.c:41-67`）
- popen `at+csq`，多行扫描找 `+CSQ:`，`p+=5` 后 `sscanf("%d",&rssi)` 取逗号前第一数字。返回 0-31/99，失败 -1。
- **返回值语义**（注释）：0-31 正常，99 无信号，-1 失败。

### `int get_cereg_status_safe(void)`（`at.c:71-98`）
- popen `at+cereg?`，找 `+CEREG:`，定位第一个逗号后 `atoi` 取 `<stat>`。返回 0-5，失败 -1。
- **注意**：仅取第一个逗号后的字段。若响应是 `+CEREG: <n>,<stat>` 正确；此处依赖模块回显格式（代码假设 `+CEREG: n,stat,...`）。

### `int get_qiact_status_safe(char *ip_buf, int ip_buf_len)`（`at.c:103-125`）
- `at+qiact?`（一行），含 `+QIACT:` 且含 `,1,1,` 判为激活（返回 1），并从首个引号提取 IP 到 ip_buf。否则 0。**工程内未见被 dial.c 调用**（build 用 cgpaddr）。

### `get_imei_safe` / `get_imsi_at_safe`（`at.c:129-165`）
- `at+cgsn` / `at+cimi`，逐行跳前导空白，取纯数字段，长度 `>=14` 且后接串尾/换行则 `snprintf` 输出。IMEI/IMSI 14-16 位纯数字校验。

### `static get_operator_safe`（unused，`at.c:169-185`）
- `at+cops?` 取 `+COPS:` 整行去换行。当前 dial.c 已注释调用。

### `get_cesq_safe` / `get_creg_safe`（`at.c:191-228`）
- `at+cesq` / `at+creg?`，取首个匹配 `+CESQ:`/`+CREG:` 行，`strncpy` 到 out，去 `\r\n`。注释含 RSRP/RSRQ 换算公式与 CREG 小区字段格式。

### `static get_cfun_safe`（unused，`at.c:232-248`）
- `at+cfun?` 取 `+CFUN:` 行。dial.c 中已注释调用。

### `get_cgmr_safe`（`at.c:254-273`）
- **用 `at+qgmr`**（Quectel 私有，注释说明 CGMR/GMR 部分固件返回占位符）。逐行跳空白、跳过以 `AT`/`OK`/`ERROR` 开头的行，取首个有效版本行。

### `get_csub_safe`（`at.c:277-295`）
- `at+csub`，找 `SubEdition:`，跳前缀 11 字节+空格取版本。

### `get_zcgmr_safe` / `get_acgmr_safe`（`at.c:299-342`）
- `at*zcgmr`（AP 侧固件）/ `at*cgmr`（CP 侧固件），跳前缀+引号，取到引号/换行前。注释含 ASR1803 AP/CP 版本示例。

### `static get_cgdcont_safe`（unused，`at.c:346-364`）
- `at+cgdcont?` 多条 `+CGDCONT:` 用 ` | ` 拼接。dial.c 已注释。

### `get_nw_mode_pref_safe`（`at.c:368-384`）
- `at+qnwprefcfg=\"mode_pref\"`（注意命令里对引号做了 `\\\"` 转义），取 `+QNWPREFCFG:` 行。

### `get_cgpaddr_safe`（`at.c:388-406`）
- `at+cgpaddr` 多条 `+CGPADDR:` 用 ` | ` 拼接。

### `get_qtemp_safe`（`at.c:410-426`）
- `at+qtemp` 取 `+QTEMP:` 行（模块温度，注释说部分平台返回 ERROR）。

### `get_ceer_safe`（`at.c:430-446`）
- `at+ceer` 取 `+CEER:` 行（最近错误原因）。

### `get_cgact_safe`（`at.c:450-468`）
- `at+cgact?` 多条 `+CGACT:` 用 ` | ` 拼接（PDP 激活状态）。

### `int build_ext_line(buf, len, qcsq, cell, ip, temp, ceer, cgact)`（`at.c:473-615`）
把各 AT 原始响应解析+格式化为 `key:val | key:val`，返回写入字符数。NULL/空字段跳过。字段顺序：
1. **RSRP/RSRQ**（`at.c:489-503`）：从 CESQ 冒号后 `sscanf` 6 个整数，第 5=rsrq_raw 第 6=rsrp_raw，`!=255` 才算；`RSRP=rsrp_raw-141`，`RSRQ=rsrq_raw/2-19`。
2. **CID**（`at.c:508-532`）：扫 CREG 的第 3、4 个引号之间 ci 字段（长度 <16）。
3. **IP**（`at.c:537-558`）：CGPADDR 逗号后跳空格/引号取到引号/空格/`|`。
4. **Temp**（`at.c:562-581`）：QTEMP 第二个引号对内数值。
5. **CEER**（`at.c:585-600`，DIAG 专用，心跳传 NULL 跳过）。
6. **PDP**（`at.c:604-612`，DIAG 专用）：cgact 原样拼入。
- 每段拼接前用 `pos>0` 决定是否加 ` | `，边界检查 `pos+n < len`。

### `void get_cpin_status_str(char *out_buf, int len)`（`at.c:618-656`）
- `at+cpin?`。popen 失败 → 打 `[WARN]` 并置 out_buf=`ERROR`。默认置 `UNKNOWN`；找到 `+CPIN: ` 后 `p+=7`、截断换行、`strncpy` 到 out_buf。这是回调未初始化时 ST_SIM/心跳的回落查询。

## 四、潜在问题 / 需实测确认

1. **每个 getter 都 fork+popen 外部 `serial_atcmd`**：30s 心跳约 4 次、5min 扩展心跳 3 次、DIAG 快照 6 次、每次故障期高频。串行阻塞主循环。**serial_atcmd 单次耗时/超时行为需实测**（尤其 AT 端口忙时）。
2. `build_ext_line` 各 `snprintf` 返回值 n 可能 `>= len-pos`（截断时 n 为"本应写入"长度），条件 `pos+n < len` 能防止 pos 越界推进，安全。
3. `get_cereg_status_safe` 只解析第一个逗号后字段，若某固件 CEREG 格式变化（如无 `<n>` 前导），解析会偏。**需实测目标固件 CEREG 回显格式**。
4. 三个 `unused` getter（operator/cfun/cgdcont）编译进二进制但无调用者，属备用。
5. `exec_cmd_safe` 只读一行——用于 QIACT 单行响应；若响应首行不是目标行会漏解析（QIACT 依赖 serial_atcmd 直接回显 `+QIACT:` 在首行，需实测）。
