# 05 — nw/nw.c + nw/nw.h

## 一、文件职责概述

`nw.c` **绝大部分是 Quectel 官方 sample 的交互式测试菜单代码**（`item_ql_nw_*` 系列，用 `t_get_int`/`scanf` 读键盘输入，`printf` 打印），文件头即标注 `@file m_nw.c / nw test module`。这些 `item_*` 函数注册进 `ql_nw_module` 测试菜单（`nw.c:1517-1550`），**在 open_dial 运行期（main→dial_loop）完全不被调用**。

真正被本工程其它模块使用的只有 3 个工具函数（经 grep 核实）：
- `nw_get_if_statistics_rx_packets()` — 被 data_call.c 调用
- `nw_mark_network_status()` — 被 data_call.c 调用
- `internal_nw_get_signal_strength_level()` — 导出供 dial 层信号等级字符串化（间接）

`nw.h` 定义路径宏 `NW_IF_STATISTICS_RX_PACKETS_PATH`、`NW_CSQ_PATH=/tmp/network_csq`、`NW_STATUS_PATH=/tmp/network_status`。

## 二、关键宏
| 宏 | 值 |
|---|---|
| `NW_IF_STATISTICS_RX_PACKETS_PATH` | `/sys/devices/virtual/net/%s/statistics/rx_packets`（nw.h:7） |
| `NW_CSQ_PATH` | `/tmp/network_csq`（nw.h:9） |
| `NW_STATUS_PATH` | `/tmp/network_status`（nw.h:10，misc.c 亦用此文件） |

## 三、逐函数分析（按用途分组）

### （A）实际被工程使用的函数

#### `bool nw_get_if_statistics_rx_packets(uint64_t *p_rx_packets, char *if_name)`（`nw.c:1553-1576`）
- 拼 `/sys/.../<if>/statistics/rx_packets` 路径，`open(O_RDONLY)`；`lseek` 求文件大小，`0 < size < 256` 才读；`read` 到 `val_bytes`，`strtoull` 转 `*p_rx_packets`。成功 true，失败 false。
- **潜在点**：`read()` 返回值未检查（`nw.c:1572`）；`file_size` 用 `lseek(SEEK_END)` 对 sysfs 文件通常返回内容长度（sysfs 特殊，需实测该文件 lseek 行为是否可靠）。

#### `void nw_mark_network_status(int net_status)`（`nw.c:1737-1749`）
- `open(NW_STATUS_PATH, O_WRONLY|O_CREAT|O_TRUNC, 0644)`，`sprintf` 整数写入。
- **注意**：与 misc.c 的 `write_status`/`update_network_status` 写的是**同一文件** `/tmp/network_status`，但一个用 raw `open/write`（无 `\n`），一个用 `fprintf("%d\n")`（有 `\n`）。两条写路径格式不完全一致（需注意读取方兼容性）。

#### `int internal_nw_get_signal_strength_level(level, buf, buf_len)`（`nw.c:1208-1247`，**非 static，导出**）
- 将 `QL_NW_SIGNAL_STRENGTH_LEVEL_E` 枚举映射为 NONE→"UNKNOWN"/POOR/MODERATE/GOOD/GREAT 字符串。识别返回 1，未知返回 0。

### （B）SDK 事件回调（sample，运行期未注册使用）
`nw_voice_reg_event_ind_cb`（`nw.c:35-101`）、`nw_data_reg_event_ind_cb`（`nw.c:103-169`）、`nw_signal_strength_event_ind_cb`（`nw.c:171-240`）、`nw_cell_access_status_event_ind_cb`、`nw_nitz_time_update_event_ind_cb`、`nw_wea_alert_event_ind_cb`、`nw_etws_alert_event_ind_cb`、`nw_network_scan_async_cb`、`nw_service_error_cb`（`nw.c:334-337`，仅 printf）。均只 `printf` 打印回调内容，不写任何供 dial 使用的标志。

### （C）交互式测试菜单函数（sample，运行期不调用）
`item_ql_nw_init/deinit/network_scan/set_power_mode/set_pref_nwmode_roaming/get_*/set_*_ind_cb/wea_*/etws_*` 等（`nw.c:339-1515`）。特点：用 `t_get_int`/`t_get_hex`/`scanf`/`getchar` 读输入——**在无 TTY 的守护进程环境下这些会阻塞或立即 EOF 失败**，但由于运行期不调用，无影响。`item_ql_nw_set_power_mode`（`nw.c:387-401`）中 `ret` 已初始化为 0（`nw.c:389`），但读输入的 `t_get_hex(&mode)` 被注释掉（`nw.c:393`），导致 `ret` 恒为 0、输入校验 `if(ret!=0)`（`nw.c:394`）成**死分支**，`mode` 恒为 0 直接传给 `ql_nw_set_power_mode`——**sample 遗留缺陷，但函数无调用者**。（更正：非"未初始化 ret"，`ret` 在 389 行已置 0）

### （D）内部转换 helper（static）
- `internal_nw_get_mcc_mnc_value`（`nw.c:949-978`）：从 3 字节 PLMN BCD 解码 mcc/mnc。
- `internal_nw_get_net_status`/`internal_nw_get_radio_tech`/`internal_nw_get_tech_domain`/`internal_nw_get_service_option`（`nw.c:980-1310`）：枚举→字符串映射。均只被 sample item 函数使用。

### （E）其它未被调用的工具函数
- `nw_set_pref_nwmode_roaming`（`nw.c:1579-1590`）：设 `QL_NW_MODE_LTE` + 漫游 ON，`ql_nw_set_pref_nwmode_roaming`。**无调用者**。
- `nw_get_signal_strength`（`nw.c:1593-1617`）、`nw_get_status`（`nw.c:1620-1636`）、`nw_get_data_reg_status`（`nw.c:1639-1704`）：均无工程内调用者，仅 printf。
- `int get_signal_strength(QL_NW_SIGNAL_STRENGTH_LEVEL_E *level)`（`nw.c:1707-1735`）：`ql_nw_get_signal_strength`，成功则 `system("echo <level> > /tmp/network_csq")`。**无工程内调用者**（信号采集运行期实际走 at.c 的 `get_csq_value_safe`）。

## 四、潜在问题 / 需实测确认

1. **本文件约 95% 是 sample 死代码**：`item_*` 交互菜单、多数回调、`nw_get_*` 均无运行期调用者。它们仍参与编译（增大二进制、引入 `scanf`/`t_get_int` 依赖）。**需确认是否有意保留（作 SDK 参考/调试菜单）**。
2. **两条写 `/tmp/network_status` 的路径格式不一致**：`nw_mark_network_status`（无换行）vs misc.c `write_status`（`%d\n`）。读取方 `read_status` 用 `fscanf("%d")` 对两者都能解析，实际兼容；但格式不统一是隐患。
3. `nw_get_if_statistics_rx_packets` 的 `read()` 返回值未检查（`nw.c:1572`）；sysfs `lseek(SEEK_END)` 求大小对部分内核 sysfs 节点可能返回 0/4096，**需实测该节点行为**。
4. `internal_nw_get_service_option` 的 `strcat(buf + (buf_len - remain_len), ...)` 指针算术依赖 remain_len 维护，逻辑正确但可读性差（sample 遗留）。
5. sample `item_ql_nw_set_power_mode`：`t_get_hex` 读输入被注释（`nw.c:393`），`ret` 恒为 0 使 `if(ret!=0)`（`nw.c:394`）成死分支、`mode` 恒 0——非"未初始化"，`ret` 在 `nw.c:389` 已初始化为 0。因无调用者不触发。
