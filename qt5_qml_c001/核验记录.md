## 实际构建核验

### 主应用

在临时工作目录执行（环境脚本内容已先读取）：

```bash
source /home/tronlong/RK3576/rk3576_linux6.1_release/buildroot/output/rockchip_rk3576/host/environment-setup
cd /tmp/qt5_qml_c001_init_audit.Y3eyWx
qmake /home/tronlong/lyp/code/qt5_qml_c001/qt5_qml_c001.pro
make -j2
```

qmake 成功生成 Makefile；make 在编译 `CameraProvider.cpp` 和 `camera_shm_multi.cpp` 时失败：

```text
fatal error: gst/gst.h: No such file or directory
make: *** [Makefile:880: camera_shm_multi.o] Error 1
make: *** [Makefile:876: CameraProvider.o] Error 1
```

当前 SDK 的 `sysroot/usr/include/gstreamer-1.0/gst/gst.h` 存在，编译命令却使用 `.pro` 中残留的 `/home/xp/rk3576/.../usr/include/gstreamer-1.0`。该目录在当前主机不存在。因此首个失败可归因于头文件搜索路径不匹配，不能直接写成“SDK 未安装 GStreamer”。

`.pro` 中同时存在 `/home/tronlong/RK3576/`、`/home/xp/rk3576/`、`/home/xp/android_sys/` 等绝对路径；`tests/pkg-config_wrapper.sh` 还有 `/mnt/mydisk/`。当前后面三类已检查的 sysroot 目录不存在。部分 RKNN/RGA/private Qt 路径也需要统一，但本次不修改源码或声明剩余构建问题已经解决。

本次没有继续通过临时 include 覆盖绕过此失败，因此主应用后续编译、最终链接、QML 插件、硬件运行均未证明。
